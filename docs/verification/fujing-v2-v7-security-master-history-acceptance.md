## 阻塞原因

- Baostock 历史接口只接受 `sh/sz`，北交所代码明确不支持。
- 当前可用 AKShare 接口只有当前 ST 快照或缺日期的名称序列，不能替代北交所历史点时事实。
- 两个全量任务均因北交所隔离而被拒绝，没有生成新的质量报告或发布版本；最新正式版本仍为 `scq-20260810-c8c0fda697c9280b`。

## 潜在风险

- `available_at=trade_date` 是基于日频 `isST` 为当日状态的候选口径，未来正式来源应提供更细的生效/公告时间。
- SDK 开源许可不等于上游数据商业授权。
- 版本回放机制已经验证，但当前活动快照仍属于本地候选事实；在覆盖完整并正式发布前，不得用于正式 OOS 证据。
