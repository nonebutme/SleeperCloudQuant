# 拂经 v2 V7 raw-v2 原值纠偏验收

> 后续口径更新：本文关于raw-v2关闭MAD缩尾的结论继续有效；其中每日等权+强制
> Top-N下的收益、回撤和V6/V7绩效数值，已被
> `fujing-v2-v7-event-driven-incumbent-acceptance.md`按用户确认的新执行语义取代。

## 已验证项

- 发现旧开发任务虽设置 `standardize=false`，仍保留 `winsor_mad=3.0`；旧制品发布
  的是缩尾后 `processed_value`，不符合V7固定业务阈值所需的原值语义。
- 旧任务受影响：WINNER-low/high/spread分别有38,989/28,646/34,274行被改变，
  默认阈值翻转4,855/9,937/10,756行；振幅比例有41,395行被改变、460行翻转。
- 保留旧任务和制品供审计，新增 `raw-v2` 任务，显式设置
  `winsor_mad=0、industry_neutral=false、standardize=false`。
- 五个raw-v2制品共1,715,260行，数据库级逐项核对
  `raw_value == processed_value`，差异为0：
  - WINNER-low：`factor-artifact-6bced7f3d995179eec6b`；
  - WINNER-high：`factor-artifact-ce8a3db1c23480a1ccbf`；
  - WINNER-spread：`factor-artifact-6c7b6d599e0c159ea443`；
  - 16日低点：`factor-artifact-c692e817e62e3be918fb`；
  - 振幅比例：`factor-artifact-dc847299abb85703271f`。
- 原值默认信号为900行、覆盖176只，年度分布为
  `17/82/104/80/110/102/102/196/107`。旧缩尾版228行、116只的结论已撤销。
- 原值默认共享组合累计收益 `-42.2517%`、沪深300 `13.4285%`、超额
  `-49.0884%`、最大回撤 `-63.7834%`、Sharpe `-0.1602`。
- 七组事前敏感性仅移动止损0.90取得正累计收益 `9.3023%`，但超额仍为
  `-3.6377%`、最大回撤 `-39.7318%`；其余六组均为负收益。
- 原值V6/V7同输入入场事件为704/700，同标同日692，Jaccard `0.9719`；
  持仓行Jaccard `0.9731`。V6/V7累计收益分别为 `-42.0233%/-42.2517%`。
  旧缩尾版“V7显著改善V6”的结论已撤销。
- 199只独立账户中181只有成交、81只正收益；收益中位数 `-0.1885%`。
- 所有结果仅使用2024-12-31及以前数据，封存OOS仍未读取，V7仍非活动。

## 未验证项

- 尚无参数或策略结构通过正超额、回撤和跨阶段稳定性门槛。
- 尚未完成16日低点、退出路径的进一步消融，以及市场状态分层、风险预算重构和
  全股票池验证。
- 振幅、spread、高位、低位的单条件消融及三项账户风险覆盖已完成，见
  `fujing-v2-v7-development-ablation-risk.md`；16日低点、退出路径和市场状态仍待验证。
- 全股票池分区制品机制尚未实现；若启用横截面预处理，不能直接合并各分区
  processed值，必须先合并raw值再做全市场统一处理。

## 阻塞原因

- 默认及全部事前邻域均未同时满足正超额和可接受回撤，当前不具备OOS开封前提。
- 继续扩大阈值搜索会形成开发样本追优，必须先调整策略风险和退出结构。

## 潜在风险

- 2019年单年高收益掩盖多数年份亏损，策略具有明显状态依赖。
- 缩尾配置与固定业务阈值不兼容；若未来再次启用预处理，必须使用独立研究因子，
  不得冒充策略原值制品。
- 回测不包含盘口冲击、部分成交和外部数据SLA。

## 发布判断

- raw-v2原值制品与链路：`通过`。
- 旧缩尾版信号、绩效和V6/V7改善结论：`撤销`。
- 默认策略有效性：`未通过`。
- 参数冻结、V7激活、OOS开封：`禁止`。
