## 阻塞原因

- 真实研究仍需要历史风险警示/名称区间事实、对应 reader，以及冻结后的开发/OOS 研究方案。
- 制品发布必须建立在真实研究任务和质量证据上，不能用合成黄金样本替代。

## 潜在风险

- WINNER 仍是日线代理，其排序与原生筹码分布可能存在系统偏差。
- “低点事件”和“振幅比例”是两个独立因子；策略组合逻辑与阈值仍应留在策略层，不应伪装成原始事实。
- 当前定义已发布到代码目录不等于已有可消费的因子值制品。
