# 统一入口验收（2026-09-14）

## 需求与差异

已确认：日常仅使用 `启动系统.cmd`，所有正式业务从 `http://127.0.0.1:8010/` 进入。内部脚本保留，开发候选须明确区分。

| 入口 | 已核对能力 | 本轮处置 |
| --- | --- | --- |
| 8010 正式 Web/API | 数据中心、因子、策略数据集、策略与回测、报告、设置 | 保持主服务；增加就绪接口及启动检查 |
| 8020 策略工作室 | 主服务能力外，另有数据集产品目录、版本化策略清单 API | 保留开发候选，必须传 `--developer-mode`；不自动提升为正式功能 |
| 8000 纯 API | 主服务 API 的独立调试入口 | 必须传 `--developer-mode` |
| `web/strategy-studio.html` | 候选页面，依赖候选 API | 8010 下跳转正式策略页；开发页提供返回正式系统链接 |

内部链路：`启动系统.cmd` → `scripts/start_sleepercloudquant.ps1` → `scripts/run_formal_web_demo.py`。README、Manifest、运行说明、启动清单统一采用此口径。未删除或移动候选代码。

## 阻塞原因

入口统一无阻塞。候选工作室仍保留其原有候选定位，独有功能尚未晋升主系统。

## 潜在风险

旧版本服务没有新增健康接口时，启动器会提示使用停止入口后重新启动。开发诊断仍可显式使用其他端口；该能力不作为日常用户入口。

## 发布判断

统一入口已实现并验证，可按正式启动链使用；本结论不替代此前数据质量及业务验收结论。本轮启动服务，未触发行情更新、回测或纠错操作。
