## 阻塞原因

- Baostock 仅识别 `sh/sz`，对北交所明确返回不支持；继续重试同一来源不会产生新事实。
- 北交所历史风险警示、历史名称以及版本化快照需要新的有授权来源或受治理补充机制。

## 潜在风险

- stage 78.3 质量门只要求交易状态已物化，不检查交易日历内部连续性；本轮出现“任务发布成功但中间六个开市日缺失”的情况，已通过发布后交叉审计发现并修正。
- AKShare/Baostock 仅用于本地非商业研究；Baostock SDK 的 BSD 许可不等于上游数据商业授权或 SLA。
- 不得根据当前名称倒推历史 ST 状态，也不得用停牌状态代替风险警示状态。
- `isST` 的 `available_at=trade_date` 采用日频字段为当日状态的口径，仍需在未来正式来源合同中固化更细时间语义。
