## 阻塞原因

- 若要做精确归因，需要建立一次只改变一个语义的V6→V7消融版本；这些版本只能
  作为分析夹具，不得写入正式策略库或冒充真实历史版本。
- 全股票池比较仍依赖分区/流式因子制品机制。

## 潜在风险

- V7相对V6显著改善并不等于V7绝对有效；V7仍跑输沪深300且最大回撤接近46%。
- V7信号在2023年仍显著集中，2024年仅6次入场，存在状态依赖。
- 本次V6为了可比性使用V7治理后的点时输入，因此不是对V6既有历史任务的复刻。
