# 拂经 v2 V7 开发期敞口匹配基准诊断

## 已验证项

- 使用已确认的事件再平衡、存量优先和15%单票上限，保持raw-v2、199只冻结队列、
  2016—2024开发窗口；未读取2025年后数据。
- 敞口匹配基准每天使用“前一交易日收盘股票总敞口 × 下一交易日沪深300收益”，
  剩余现金收益固定为0，避免使用当日结果决定当日基准暴露。
- 默认V7平均/中位股票敞口为 `25.04% / 18.29%`。
- 全期结果：

| 指标 | V7 | 敞口匹配沪深300 |
| --- | ---: | ---: |
| 累计收益 | 17.87% | -1.02% |
| 最大回撤 | -17.10% | -30.33% |
| 年化波动 | 8.47% | 6.92% |

- V7相对敞口匹配基准的乘法超额为 `19.09%`。因此默认结果不能仅用“多数时间
  持有现金”解释。

| 年份 | V7 | 敞口匹配基准 | 乘法超额 |
| --- | ---: | ---: | ---: |
| 2016 | 2.45% | -1.23% | 3.72% |
| 2017 | -8.83% | 3.39% | -11.82% |
| 2018 | -4.90% | -3.08% | -1.88% |
| 2019 | 34.27% | 16.04% | 15.71% |
| 2020 | -8.94% | 8.84% | -16.34% |
| 2021 | 0.32% | -4.34% | 4.86% |
| 2022 | -2.27% | -13.18% | 12.57% |
| 2023 | 14.85% | -8.29% | 25.23% |
| 2024 | -3.61% | 3.95% | -7.27% |

- 9年中5年相对敞口匹配基准为正、4年为负；优势主要集中在2019、2022、2023，
  2017和2020明显落后。

## 未验证项

- 尚未进行行业、风格、市值和波动Beta匹配。
- 现金收益按0处理，尚未加入历史无风险利率或货币基金收益。
- 尚未扩展至点时全A股；封存样本外仍不可见。

## 阻塞原因

- 199只开发队列不足以证明全A适用性。
- 点时全A扩展需要为五个因子生成大规模不可变制品；在执行前需要核算预计行数、
  数据库增量、运行时间和磁盘余量。

## 潜在风险

- 动态敞口本身是策略结果，敞口匹配基准不是完全独立的投资基准。
- 只匹配总市场敞口会遗漏行业和风格暴露。
- 根据2017、2020等已知弱年直接设计市场门禁会形成开发样本追优。

## 发布判断

- “正收益只是因为持有现金”：`不成立`。
- 同风险暴露下的稳定优势：`部分成立但年度稳定性不足`。
- 参数冻结/OOS开封：`禁止`。
- 下一阶段：`先完成点时全A因子制品资源评估，再决定是否执行全量开发验证`。
- 资源评估已完成：磁盘满足，但当前内存和SQLite事务机制不满足直接全量，详见
  `fujing-v2-v7-full-a-resource-readiness.md`。
