## 4. 可读性与边界

- 指标卡展示指标值、计算口径或不可用原因。
- 极小非零比率使用四位小数，避免 `0.00136` 被误显示为 `0.00`。
- 桌面端指标卡四列，移动端两列；长原因允许自动换行。
- 独立账户报告持续显示“独立账户、无限资金”警告，不提供汇总总净值。
- 参数敏感性、月度热力、市场环境、行业 IC 等缺少真实序列的区域保留明确空状态。
