# 拂经 v2 V7 事件再平衡与存量优先验收

## 已验证项

- 用户已确认组合执行语义：`event_driven + incumbent_priority`。
- 事件再平衡使用固定槽位：新持仓初始目标权重为“组合敞口÷最大持仓数”；当前
  开发配置为 `90%÷10=9%`，空槽保留现金。名单不变时不因价格变化每日恢复等权。
- 存量优先：已有正策略目标的持仓保留至策略退出；新信号只使用空位，不能仅因
  入场分数更高而强制替换旧持仓。
- 正式共享组合接口新增两个显式字段，旧任务默认仍为
  `daily_equal_weight + force_top_n`，没有静默改变历史语义。
- V7 源码声明 `PORTFOLIO_EXECUTION_CONTRACT`；任务没有显式覆盖时自动绑定策略
  声明。旧策略没有声明时回退兼容默认。Web 工作台默认选择“按策略声明”。
- 专项验证确认：事件再平衡且存量优先时，三日名单未退出只产生首日两笔买入；
  旧默认仍会卖出低排名存量并买入高分挑战者。
- 使用 raw-v2 五制品、199只历史合格证券、2016—2024开发窗口、同一费用滑点和
  沪深300基准重算；未读取2025年后数据。

## 阻塞原因

- 默认参数虽取得正收益和正超额，但2019—2021段显著跑输基准，信息比率仍为负，
  不满足稳定性冻结条件。
- 消融中取消高位排除取得35.84%开发收益、调整low阈值取得28.44%，但这些都是
  已查看开发结果，不能直接追选为新默认。

## 潜在风险

- 事件再平衡允许权重随价格漂移；15%门禁已限制集中风险，但收盘超限至下一开盘
  之间仍存在隔夜价格风险。
- 默认配置单票最大权重14.57%，宽松止损配置最大17.50%；风险不是假设性缺口。
- 固定9%槽位在候选不足时保留大量现金，收益与基准的风险暴露不同；正超额不能
  单独证明选股能力。
- 敞口匹配后V7相对收益为19.09%，现金不能解释全部表现；但仅5/9年度为正，优势
  仍集中于2019、2022、2023。
- V6/V7同口径表现近似，V7当前价值主要是点时数据、因子制品和可复现治理。

## 发布判断

- 执行机制：`已实现并通过专项验证`。
- 旧任务兼容性：`保留`。
- V7开发证据：`由负收益纠正为正收益，但稳定性仍不足`。
- 参数冻结：`禁止`。
- 封存样本外：`继续不可见`。
- V7激活或资金部署：`禁止`。
