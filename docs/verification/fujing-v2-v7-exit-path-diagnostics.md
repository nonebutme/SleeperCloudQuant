# 拂经 v2 V7 开发期退出路径诊断

> 已完成机制纠偏：本文旧数值用于证明每日等权和强制Top-N造成混合卖出路径。
> 用户已确认事件再平衡+存量优先，当前权威结果见
> `fujing-v2-v7-event-driven-incumbent-acceptance.md`。

> 退出原因细分更新：此前“平均亏损卖出成交改善”是全体卖出成交的混合口径，
> 不能归因于止损本身。精确按策略目标与组合目标拆分后，0.90 相对 0.95 的
> 净改善主要来自 Top-N 容量选择和持仓再平衡，止损退出只贡献较小部分。

## 已验证项

- 使用 raw-v2 五制品、199 只历史合格证券、2016—2024 开发窗口和同一正式共享组合核心；仅比较移动止损参数，未读取 2025 年后封存样本外。
- `0.90` 是比默认 `0.95` **更宽松**的移动止损：它允许价格从持仓后高点回撤约 10%，而 `0.95` 约为 5%。

| 诊断项 | 默认止损 0.95 | 宽松止损 0.90 |
| --- | ---: | ---: |
| 已闭合持仓段 | 714 | 715 |
| 持有日历天数 P05/P25/P50/P75/P95 | 1 / 4 / 8 / 16 / 35 | 2 / 7 / 18 / 37 / 85 |
| 已实现卖出成交 | 2,918 | 5,692 |
| 盈利/亏损卖出成交 | 1,770 / 1,148 | 3,409 / 2,283 |
| 已实现损益合计 | -422,516.84 | 93,023.50 |
| 平均盈利卖出成交 | 2,242.98 | 1,187.17 |
| 平均亏损卖出成交 | -3,826.30 | -1,731.95 |
| 最差 10 次亏损占全部亏损 | 12.50% | 10.88% |

- 更宽松的 `0.90` 将持仓中位数从 8 天延长到 18 天，同时把平均亏损卖出成交的绝对值从约 3,826 降到约 1,732；改善不是“更早止损”的结果。
- 使用成交日策略目标与组合目标还原卖出原因；没有改动正式回测运行器：

| 卖出原因 | 默认 0.95：成交 / 已实现损益 | 宽松 0.90：成交 / 已实现损益 | 损益变化 |
| --- | ---: | ---: | ---: |
| 策略目标归零 | 680 / -1,729,293 | 559 / -1,691,328 | +37,965 |
| 策略目标仍正、Top-N容量剔除 | 34 / 37,508 | 156 / 366,059 | +328,552 |
| 策略及组合目标仍正、权重再平衡 | 2,204 / 1,269,269 | 4,977 / 1,418,292 | +149,023 |

- 两方案总损益差约 `+515,540`：策略目标归零部分仅解释约 `7.4%`，容量剔除约
  `63.7%`，权重再平衡约 `28.9%`。因此不能把 0.90 的改善解释为“止损质量
  提升”；主要证据指向持仓持续时间与 Top-N 排名、组合再平衡之间的交互。
- Top-N选择路径进一步确认：

| 选择路径指标 | 默认 0.95 | 宽松 0.90 |
| --- | ---: | ---: |
| 有正目标的交易日 | 1,679 | 1,929 |
| 活跃候选数 P50 / P95 | 3 / 9 | 7 / 18 |
| 超过10只的交易日 | 52（3.1%） | 473（24.5%） |
| Top-N新入选 / 退出 | 719 / 718 | 723 / 722 |
| 仍有正目标但被容量挤出 | 34 | 155 |
| 连续入选交易日 P50 / P95 | 5 / 24 | 11 / 56 |
| 相邻交易日名单Jaccard P50 | 1.00 | 1.00 |

- 名单相邻日重合度中位数均为 1.00，不能描述为普遍的“排名抖动”。0.90 的主要
  变化是持仓延长后候选拥挤：超过容量的日期由 3.1% 升至 24.5%。
- 当前共享组合每天将90%敞口在入选股票间重新等分并重算股数。因此即使名单不变，
  也会卖出部分上涨持仓、补买部分下跌持仓；这属于尚未确认的每日等权再平衡语义。
- 年度已实现损益显示，`0.90` 的正贡献不只来自 2019 年，2020、2021、2023 年也为正；但 2016、2017、2018、2022、2024 年仍为负。

| 退出年份 | 默认止损 0.95 | 宽松止损 0.90 |
| --- | ---: | ---: |
| 2016 | -10,892 | -95,369 |
| 2017 | -199,476 | -37,724 |
| 2018 | -171,936 | -256,228 |
| 2019 | 562,134 | 359,395 |
| 2020 | -381,860 | 98,884 |
| 2021 | -94,109 | 151,942 |
| 2022 | -101,773 | -126,596 |
| 2023 | 136,283 | 113,710 |
| 2024 | -160,887 | -114,991 |

- 与既有三段结果合并判断：`0.90` 全期累计收益为正，但超额收益仍为负，且三段收益为 `-38.50% / 106.01% / -13.72%`，不能视为稳定优势。

## 未验证项

- 已区分策略目标归零、Top-N容量剔除和正目标再平衡；尚未建立完整的闭合持仓段
  成本归因，故各类已实现损益不能被解释为彼此独立的经济贡献。
- 尚未验证时间止损、市场状态门禁、组合级回撤控制，亦未形成新的候选策略语义。
- 尚未确认“每日等权/事件再平衡/固定周期再平衡”和“每日强制换榜/存量优先/固定
  周期换榜”两项组合执行语义。
- 尚未在封存样本外验证；封存区间继续保持不可见。

## 阻塞原因

- 当前交易记录中的一次卖出成交可能只是部分减仓；卖出原因分类已解决行为来源，
  但仍不能把每条成交解释为独立完整交易。持有期只按仓位从零到非零再回到零
  的闭合段计算。
- `0.90` 的改善跨越数年但仍存在明显负收益年份与阶段集中，现有证据不足以把单一参数提升为冻结规则。

## 潜在风险

- 把 `0.90` 误称为“更紧止损”会产生完全相反的业务解释。
- 根据本轮结果直接选择 `0.90`，会构成开发样本参数追优。
- 卖出成交数增加不等于完整交易次数增加，若混用口径会误判换手和盈亏比。

## 发布判断

- 默认 `0.95` 的退出路径：`不能单独解释亏损；策略目标归零损失与组合再平衡收益
  同时存在`。
- `0.90` 的开发期表现：`主要改变组合容量和再平衡路径，不能作为单一止损参数直接
  冻结或发布`。
- V7 状态：`保持非活动；参数未冻结；封存样本外未查看`。
- 下一决策入口：`先冻结组合排名持续性和再平衡频率语义，再讨论时间止损与市场
  状态门禁`。
