# 阶段 87 因子分析验证基线

## 1. 目标

验证 87.0 治理冻结、87.1 P0 因子研究闭环和 87.2 指数池与增强分析。任何证据缺失均不得用演示数据或静默降级掩盖。

## 2. 分层验证

### A. 公式单元验证

- 六个 P0 因子使用手工可复算序列，覆盖首个有效日、零分母、缺失 amount 和常量序列。
- Pearson、平均秩 Spearman、MAD 去极值、行业去均值、Z-score、ICIR、t 值、等频分组、换手和最大回撤均有确定性样例。
- 未来收益严格按交易日位移，不按自然日。

### B. 存储与状态机

- Schema 初始化幂等。
- 因子定义按 factor_id + factor_version 唯一。
- context_hash 对键顺序稳定，对配置变化敏感。
- 任务重启后 running 转 interrupted。
- stop、retry-failed 不更换冻结上下文。
- 报告载荷哈希可复算，报告读取不触发重算。

### C. 预检与数据治理

- 只自动选择最新 published，不自动选择 superseded 默认指针。
- 请求区间超过成员交集时返回 effective_range 或阻断原因。
- P0 全 A 池不读取演示成员。
- 指数事实缺失返回 index_component_facts_unavailable。
- 行业事实缺失只影响行业中性化/行业 IC 能力并明确披露。
- 业务行情库在研究执行前后保持只读。

### D. HTTP 契约

- 定义、详情、看板、预检、任务创建/启动/查询/停止/重试、报告和比较端点覆盖成功与错误路径。
- 非法日期、因子、方向、分组数、收益期、成本参数返回 400。
- 未找到任务/报告返回 not_found 语义。
- 响应包含治理冻结要求的证据字段。

### E. 真实库只读验证

- 对最新 published 版本执行小股票池、小日期窗预检和研究任务。
- 记录 data_version_id、quality_report_id、有效区间和覆盖率。
- 若本地事实不足，验证 unavailable 原因，不以外部请求补齐。
- 校验研究运行库写入，17GB 级行情库文件无业务写入。

### F. 浏览器验收

- 1440px 与 741px 视口。
- 亮色与暗色主题。
- F0→F3 导航、预检、创建任务、轮询、报告打开、停止/重试动作。
- 所有表格使用 AppVTable；窄屏无页面级横向溢出。
- 不显示 2020 演示股票池为正式指数池。

## 3. 发布门槛

- P0：公式、状态机、HTTP、真实库小样本和浏览器主路径全部通过。
- P1：指数点时事实测试、行业 IC、池间比较、执行估算全部通过；本地缺少正式指数事实时，功能可发布为 unavailable，但不得宣称数据已就绪。
- 回归：现有统一验证脚本和与因子、数据中心、VTable 相关的既有 smoke tests 不回退。

## 4. 固定结果格式

每轮报告必须包含：

- 已验证项
- 未验证项
- 阻塞原因
- 潜在风险
- 发布判断
