## 3. 关键治理边界

1. 探索研究允许指定标的或限制数量，但不能审核通过或登记给策略使用。
2. 受控研究使用完整点时股票池，并在任务创建前冻结数据版本、样本切分、预处理、成本和 `AcceptancePolicy`。
3. 样本外结果默认封存；用户显式填写原因后只记录一次解封事件，审核通过前必须已解封。
4. 研究完成先保存不可变报告，再发布 `research_ready` 制品，避免报告失败时遗留策略可用制品。
5. 策略声明和新策略参数冻结都会复核审批状态、登记状态和制品内容哈希。
6. 多因子配方固定绑定组件 `artifact_id`，不会自动追随组件最新版本。
7. 暂停只阻止新增使用，不删除历史任务、报告、制品或既有审计事件。

## 4. 验收政策 v1

受控研究当前冻结 `factor-acceptance-v1`：最低覆盖率 80%、最少 60 个样本外期间、方向一致 Rank IC 不低于 0.02、Newey-West HAC t 值不低于 1.96、正 IC 比例不低于 55%、成本后累计估算收益不低于 0、最大回撤不低于 -50%。数值未从样本外结果倒推，变更时应建立新政策版本。

多因子在上述条件外，还要求组合样本外 Rank IC 不弱于最佳单因子，并要求逐一移除组件后完整组合的 Rank IC 不下降；失败时保留报告但不能审核通过。

## 5. 兼容和迁移

- 历史报告继续可读；缺少 `research_mode` 的历史报告不套用新样本外封存逻辑。
- 历史 `ready` 制品不自动获得新的审批登记记录；创建新策略时会被统一门禁阻断。
- 历史运行按原精确 `artifact_id` 读取，不自动换成新版本。
- 原“参数优化”接口保留兼容，界面统一称为“参数敏感性分析”，结果不会自动替换已登记配方。
- 指标衍生因子不再使用独立的策略准入例外，统一通过因子制品审批与登记。

## 6. 已知边界

- 市场阶段稳定性会在报告中明确标记 `unavailable`，直到研究上下文具备经过治理的市场阶段标签；系统不会用事后划分替代点时事实。
- 样本外封存属于应用层审计门禁，不是密码学加密；本地数据库管理员仍可直接读取底层记录。
- 交易成本仍是基于 Top/Bottom 成员换手的估算，不替代账户级撮合、容量和市场冲击回测。
