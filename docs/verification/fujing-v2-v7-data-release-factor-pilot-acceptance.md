## 未验证项

- 试点仅覆盖 50 只证券，不代表点时全 A 股研究结论。
- 尚未冻结开发样本窗口、全量股票池、参数搜索空间、成交容量假设和阈值选择规则。
- 真实绑定区间的非零权重为 0；这只能证明机制可执行，不能证明当前候选阈值有效。
- 尚未创建封存 OOS 证据，未进行组合级滚动回测、敏感性分析或人工浏览器验收。

## 阻塞原因

- 进入正式开发研究前，需先形成可审计的研究方案；否则会把试点样本和候选阈值误当结论，
  并污染后续 OOS 独立性。

## 潜在风险

- 首轮标准化制品仍作为不可变历史证据保留，但不得用于 V7 业务阈值判断。
- `winner_proxy_*` 是 OHLCV 代理，不是真实筹码分布 WINNER；结论必须始终使用代理名称。
- 小样本试点的行数、覆盖率和成功状态只证明技术链路，不构成收益、稳定性或可交易性证据。

## 发布判断

- 数据版本与点时证券作用域：`已发布、可精确绑定`。
- 五因子技术链路：`试点验证通过`。
- V7 策略：`候选未激活，不可发布`。
- 封存 OOS：`尚未启动`。
