### 2.2 87.1 P0 闭环

- 因子定义：1 日收益、20/60 日动量、20 日波动率、MA20 乖离、20 日成交额强度，均为版本 v1。
- 公式验证：首个有效值、窗口、总体标准差、方向对齐、并列秩 Spearman、稳定 canonical hash。
- 预处理顺序：有限值过滤 → MAD 去极值 → 可选点时行业去均值 → Z-score → 方向对齐；逐截面保留步骤与内容哈希。
- 全 A 池读取本地价格、交易状态和生命周期事实；上市前记录不会进入研究观测。
- 任务状态：持久化创建、启动、进度、协作式停止、同上下文重试、重启后 interrupted 恢复均已验证。
- 报告不可变：同 report_id 的不同载荷写入会被拒绝。
- 指标：覆盖率、分布、IC/Rank IC、方向一致 Rank IC、ICIR、t 值、正 IC 比率、22 截面滚动值、衰减、分组收益、换手、净值和回撤。
