# 阶段 87.3 自定义因子全过程

## 使用路径

1. 打开“因子分析 → F0 因子看板”，展开“创建自定义因子”。
2. 填写因子标识、名称、分类、方向、表达式和说明。
3. 先执行“校验表达式”，确认输入字段与最少历史交易日。
4. 执行“发布新版本”。同一因子标识每次发布自动生成不可变的 `v1`、`v2`……版本。
5. 发布成功后自动进入 F1，设置股票池、日期、复权、前瞻周期、预处理、分组和成本假设。
6. 执行预检；通过后创建任务。
7. 在 F2 启动并观察任务；完成后进入 F3 查看报告及同口径报告对比。

## 表达式边界

- 字段：`open`、`high`、`low`、`close`、`volume`、`amount`。
- 窗口函数：`lag(field, n)`、`mean(field, n)`、`std(field, n)`、`min(field, n)`、`max(field, n)`。
- 标量函数：`abs(x)`。
- 运算符：`+`、`-`、`*`、`/`；窗口范围为 1–252。
- 示例：`close / mean(close, 20) - 1`。

表达式由受控 AST 解释器执行，不支持任意 Python、属性访问、导入、文件、网络或系统调用。

## 可复现性

研究任务冻结 `factor_id`、`factor_version`、`definition_hash` 和 `expression_hash`。发布新版本不会改变已创建任务和既有报告的语义；需要采用新版本时，应重新预检并创建任务。
