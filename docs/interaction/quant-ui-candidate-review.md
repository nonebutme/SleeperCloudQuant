## 已落地内容

1. 亮色/暗色双套量化 Token。
2. 256px 固定侧栏、24px 页面留白、8px 间距栅格。
3. 32px 控件、6px 卡片圆角、120px 指标卡片。
4. 红涨/盈利、绿跌/亏损，并增加箭头和无障碍描述。
5. 总览、数据中心、因子、回测、报告、配置的统一卡片与表单层级。
6. VTable 行情、回测、因子、编辑四种模式行高。
7. VTable 44px 表头、隔行色、冻结首列、金融数值色彩和箭头。
8. 顶部“量化 UI 规范 · 全局生效”标记及亮暗主题切换。

## 有意保留的技术差异

- 当前项目继续使用原生 HTML/CSS/JavaScript，不为本次视觉优化引入 React、Vue、
  Arco Design 或 Ant Design。
- 当前项目已有 SVG 图表继续保留，未引入 VChart；VTable 内嵌迷你图属于后续独立功能，
  不在本轮伪造行情或因子数据。
- 保留现有窄屏降级能力，没有强制整页最小宽度 1366px。

## 人工审核建议

重点检查：

1. 侧栏信息密度和数据中心 M0—M5 层级是否清晰。
2. 总览指标卡是否过高或信息密度合适。
3. 红涨绿跌及箭头是否符合使用习惯。
4. 暗色盯盘主题是否适合长时间使用。
5. 因子、回测、报告页面的表单与图表层级是否统一。
6. VTable 紧凑行情模式是否需要继续压缩列宽。

## 审核后的三种处理

### 接受

再将候选 Token、组件尺寸、主题规则和 VTable 模式写入项目全局技术规范与验证基线。

### 调整

保留候选隔离层，仅修改 `quant-ui-candidate.css/js` 与 VTable 候选配置，继续人工复审。

### 回退

移除 `web/index.html` 中两条候选资源引用，并撤销 `web/vtable-adapter.js`
本轮候选配置；不影响阶段 86、已有 VTable 基座或后端功能。
