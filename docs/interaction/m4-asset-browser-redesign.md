## 页面结构

M4 使用“左侧只读资产目录 + 右侧资产工作区”布局。行情目录按“股票行情 / 指数行情 / 分钟行情”分类，日线、周线、月线周期移入右侧筛选；目录同时覆盖财务、元数据、事件与资讯，并支持代码或名称检索。右侧提供：

1. 证券目录列表；
2. 个股 K 线、MA5/10/20/60 与成交量；
3. 点击 K 线交易日展开市场全景；
4. 不可用数据的明确空状态和 M2 同步入口；
5. 折叠的真实行情查询证据。

## 数据诚实性

页面不生成模拟港股/全球指数、热力图、资金流或新闻。六个核心 A 股指数使用本地治理数据；其余未接入能力统一显示“数据待接入”，引导用户前往 M2 创建同步任务。市场全景首次加载保持折叠，只有用户点击真实 K 线交易日后才展开。

## 交互约定

- 点击目录节点切换资产视图。
- 双击证券目录行或点击证券代码进入真实个股日线。
- 点击 K 线柱展开对应交易日的市场全景。
- 搜索框实时过滤目录，提交后打开第一个匹配项。
- 所有数据表由全局 VTable 适配器增强，原生表作为语义与降级载体。

## 指数数据链路

- 免费来源：项目现有 AKShare `stock_zh_index_daily`（新浪），Eastmoney curl 作为备用。
- 存储：现有 `market_index_daily_prices`，不与个股日线表混用。
- 接口：`GET /api/market/index-symbols`、`GET /api/market/index-daily`。
- 同步：`python scripts/sync_core_a_share_indices.py`，按指数代码与交易日主键增量写入。
