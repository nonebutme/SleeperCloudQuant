# 交互确认

## 页面与步骤

- `已确认` 首屏采用工作台 Dashboard，而不是单一研究入口。
- `已确认` 主导航包含：总览、数据中心、因子分析、策略回测、AI 分析、报告中心、配置中心、重构溯源。
- `已确认` 每个页面必须展示当前状态、核心指标、可执行操作和结果详情。

## 关键交互

- Dashboard 卡片可跳转到对应功能页。
- 数据中心支持查询行情、交易日历和同步状态。
- 因子分析支持加载定义、查询股票池、查看快照和 Top N。
- 策略回测支持提交单次回测，成功后可跳转到报告中心。
- AI 分析支持生成单股结构化报告，并展示依据、结论边界和风险提示。
- 配置中心展示数据源、模型、回测参数和报告模板状态。
- 重构溯源页展示五仓库来源矩阵和需求覆盖矩阵。

## 操作反馈

- 所有异步操作必须显示进行中、成功或失败状态。
- 成功结果优先渲染为摘要卡片、表格或图表，再提供 JSON 详情。
- 页面需要保留可读的 demo 数据边界提示，避免用户误认为是真实投资结论。

## 错误提示

- 错误提示必须包含操作对象、失败原因和下一步建议。
- API 返回错误时，前端显示 `detail` 字段；没有 detail 时显示 HTTP 状态。
- AI 与数据源不可用时必须明确显示是 mock 边界、配置缺失还是外部服务不可达。

## 待确认事项

- `待确认` MVP 审批后是否引入更复杂的任务队列和进度条。
- `待确认` 是否需要在 AI 报告页面加入强制免责声明确认。
