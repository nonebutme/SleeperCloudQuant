# 项目画像

## 基本信息

- `项目名称`：`SleeperCloudQuant`
- `行业`：量化分析 / 金融科技
- `产品形态`：本地化 PC Web 量化研究系统
- `目标用户`：量化研究人员、交易分析人员
- `当前阶段`：`stage-77-governance-and-results-analysis`
- `最新完成功能阶段`：`stage-76.9`

## 最终目标

`已确认` 建设一个本地运行、面向 A 股量化研究人员的 PC Web 研究工作台，完整覆盖：

1. 本地 A 股数据治理、质量门禁和版本追踪。
2. 因子定义、股票池、截面研究和因子结果读取。
3. 版本化策略编写、参数管理、源码校验和不可变版本审计。
4. 单品种测试、独立账户批量回测、投资组合回测三类回测。
5. 回测事实结果、交易/持仓/账户证据和专业分析报告。
6. 同口径 Run 对比、报告归档和 AI 辅助复盘。

`已确认` 系统不承担实盘交易执行，不输出确定性投资建议。

## 当前核心场景

- 检查 A 股数据覆盖、新鲜度和同步状态。
- 编写、校验并保存版本化策略。
- 创建并管理三种账户语义不同的回测任务。
- 查看回测事实结果、证据明细和数据版本。
- 查看模式化专业分析、证据质量和风险提示。
- 在不混用账户语义的前提下比较同模式 Run。

## 数据与合规边界

- `已确认` 数据主要保存在本地 SQLite；外部数据只通过显式 provider 或同步脚本进入。
- `已确认` 旧项目源库保持只读，规范库承担当前 A 股研究主数据。
- `已确认` 策略与回测结果属于本地研究资产，不自动上传。
- `已确认` AI 输出仅为研究辅助摘要，必须披露数据依据、证据缺口和结论边界。
- `待确认` 真实外部数据源的长期授权、频率限制和商业使用边界。
- `待确认` 真实 LLM Provider、密钥托管和报告人工审核流程。

## 当前技术画像

- Python 3.14。
- Python 标准库 `ThreadingHTTPServer` 提供本地同源 Web/API 服务。
- 自定义轻量路由、dataclass Schema、Service 与依赖装配。
- 原生 HTML/CSS/JavaScript PC Web 前端。
- SQLite 为主要持久化介质，JSON 用于少量运行草稿和索引。
- 统一验证入口：`python scripts/run_formal_verifications.py`。
