# 项目范围说明

## 任务目标

- `已确认` 建设一个 PC 端本地化 Web 量化分析 MVP，用于本地 A 股数据管理、因子研究、策略回测、AI 分析报告与回测分析报告展示。
- `已确认` MVP 必须能让用户通过 Web 页面判断功能是否正确，而不是只暴露 API 表单或 JSON 调试结果。
- `已确认` 项目需保留五个参考仓库的拆解、采纳与重构溯源，使每个核心功能能追踪到来源判断和新项目落点。

## 当前范围

- `已确认` 本阶段范围覆盖：需求基线、五仓库重构映射、后端最小服务闭环、Web MVP 产品化展示、端到端验证与验收记录。
- `已确认` 后端当前以本地 demo/runtime 数据为主，允许保留可替换的真实数据源、真实回测运行时和真实 LLM 接口边界。
- `已确认` 前端当前面向单机 PC Web 使用，不处理移动端适配和多用户协同。

## 明确不做

- `已确认` 当前不直接承诺实盘交易执行。
- `已确认` 当前不直接引入远程数据服务依赖作为 MVP 必须条件。
- `已确认` 当前不做移动端、多用户复杂权限、完整交易终端生态、复杂风控中心和多市场全量扩展。
- `已确认` 当前 AI 输出必须定位为研究辅助摘要，不输出确定性投资建议。

## MVP 范围

MVP 必须包含以下功能域：

1. 数据中心
   - 本地 A 股数据覆盖状态
   - 行情查询与趋势展示
   - 交易日历查询
   - 数据同步状态与数据源健康状态
2. 因子分析
   - 因子定义列表
   - 股票池成员查询
   - 单股因子快照
   - 截面因子摘要
   - 因子 Top N 排名
3. 策略回测
   - 单次回测提交
   - 批量回测提交
   - 回测状态、指标摘要、日志与交易摘要展示
4. AI 分析
   - 单股 AI 分析任务触发
   - 结构化分析报告展示
   - 数据依据、风险提示和 mock/真实 LLM 边界说明
5. 报告中心
   - 回测报告详情
   - 批量对比报告
   - AI 报告详情
   - 历史运行记录入口
6. 配置中心
   - 数据源配置状态
   - 模型配置状态
   - 默认回测参数
   - 报告模板与运行边界说明
7. 重构溯源
   - 五仓库来源矩阵
   - 需求到来源、模块、页面的映射
   - 直接采纳、改造后采纳、语义参考、冻结不用的边界

## 验收标准

- `已确认` 用户打开 Web MVP 首屏即可看到系统总览、核心状态和下一步操作入口。
- `已确认` 每个核心功能域都有独立页面或明确区域，且至少包含表格、图表、状态、详情中的两类可视化表达。
- `已确认` 每个页面都接入后端 API 或明确标注 demo 数据边界。
- `已确认` 后端统一验证入口必须通过。
- `已确认` Web demo 必须能启动，首页与关键 API 必须可访问。
- `已确认` 验收报告必须列出已验证项、未验证项、阻塞原因、潜在风险和发布判断。
