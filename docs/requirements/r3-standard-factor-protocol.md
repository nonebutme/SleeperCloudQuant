# R3：三项标准因子研究协议 v1

冻结时间：2026-09-14；在本轮收益计算前落盘。用户已确认：暂缓 R2 验收，研究三个标准、有效益的因子，以发现可验证的 A 股规律为交付标准。具体实验参数是本轮预注册研究选择，不代表用户已确认盈利结论。

## 假设（不按结果改方向或窗口）

| 因子 | 信号，收盘后形成 | 预期规律 |
|---|---|---|
| 短期反转 | `-(close[t]/close[t-20]-1)` | 过去约一月跌幅大的股票，后续相对收益高 |
| 中期动量 | `close[t-21]/close[t-252]-1` | 剔除最近一月后，过去约一年强势延续 |
| 低波动 | `-pstdev(最近20个交易日收益)` | 低波动股票的后续收益/风险表现更优 |

前两项是标准月度反转、12–2 动量的交易日近似，不冒称复刻原论文的规模加权因子。第三项是总波动率，不是特质波动率。

依据：[French 短期反转](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_st_rev_factor.html)、[French 动量](https://mba.tuck.dartmouth.edu/pages/faculty/ken.french/Data_Library/det_mom_factor.html)、[中国市场规模与价值研究](https://www.nber.org/system/files/working_papers/w24458/w24458.pdf)。文献只支持选题，不能证明本地样本有效。

## 固定实验

- 数据：当前治理版本的前复权日线；输入仅 2015-01-05 至 2024-12-31。研究信号 2016-01-04 至 2024-11-29；2025 年后不读取、不解封。
- 范围：有版本化历史证券状态的沪深主板、创业板；排除科创板、北交所、B 股。按 `SHA256('r3-v1:'+代码)` 排序取 600 只，保留历史身份，不按收益、当前存续或完整未来收益选股。不得称为全 A 股检验。
- 时点股票池：复用既有治理构造器；逐日证券状态、可知时间、非 ST、上市身份；共同要求此前 253 个交易日连续有效收盘，以统一三因子比较样本。
- 每 20 个市场交易日分五组，信号排序在查看未来收益之前完成；同值按代码。信号后下一交易日开盘进入，20 个交易日后开盘退出；收益区间不重叠。
- 入场停牌、无成交或一字行情：该股票份额保留现金，不事后替换。无法退出/缺价：记录未知，相关组合收益不作已知；不得删除该股票并重分组。
- 仅评估做多最高信号组；最低组用于描述，不假定 A 股可融券。同期同样本等权毛收益为对照。每次重新开平仓扣双边合计 20bp，压力 40bp；为固定保守假设，不冒称精确税费。未实现整手、每日涨跌停排队和账户级资金管理，不能冒充可执行回测。
- 2016–2020 描述，2021–2024 时间留出检验；后者不是从未被其他研究查看的独立封存集。两个由哈希顺序奇偶产生的股票子样本用于交叉核验。
- 输出五组收益、方向化 Rank IC、年度表现、净收益、超额、期末频率回撤、缺失/成交限制。净值仅按不重叠期复利。
- 统计：时间留出期净超额的 6 期循环块 bootstrap（3000 次、固定种子），报告 95% 区间及中心化单侧 p；三因子 Holm 校正。序列太短或未知退出存在时不放宽标准。

## 最短验收标准

每条规律：可复算；无未来/幸存者偏差；留出期净超额为正且 Holm p<0.05；40bp 下仍为正；四年中至少三年超额为正；两股票子样本同向；真实成交约束成立。

低波动的降风险可单列研究价值，但若不满足上述收益标准，不偷换为已验收的收益规律。三个因子全部如实交付分析，不承诺三个都有效；不足三条合格规律时 R3 未通过，不调参凑数。

## 已知门槛与实现边界

已确认生命周期表无退市事件，历史母样本完整性待核验。因此可以研究观察样本，但不能宣称消除了幸存者偏差。原研究报告的重叠期收益估计不能作本轮可投资净值，另建隔离研究脚本与证据，不修改其现有语义，不注册未验收因子为可用策略资产，不修改正式行情。
