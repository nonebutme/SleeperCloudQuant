# 业务流

## R2 已确认指标流程（2026-09-14）

选择内置指标或验证自定义表达式 → 设置参数/复权并注册 → 浏览结果或直接写策略。需要研究价值时，再选输出及转换生成因子 → 显式启动分析 → 看报告 → 填写选用依据并注册精确制品 → 策略调用。行情更新后自动检查并重算指标缓存；算法标准化不等于统计标准化。见 [操作流程](../workflows/r2-indicators.md)。

## R1 已确认整改（2026-09-13）

配置来源 → 更新数据 → 自动检查并生效 → 浏览及研究；失败保留当前数据并提示处理。历史记录用于追溯，不要求用户手动发版或切换默认。实施状态见 [R1 候选说明](../architecture/r1-data-maintenance-simplification.md)。

`已确认` 定向修复：勾选同类问题 → 填写依据（纠错另填逐项修正值）→ 一次确认 → 自动重拉/整批纠错、复检、生效。仅处理所选范围；任一失败整批撤回，未选阻断项不自动处置。

## 目标流程

- `已确认` MVP 主流程是“配置检查 -> 数据确认 -> 因子研究 -> 策略回测 -> 报告查看 -> AI 辅助分析 -> 结果复盘”。
- `已确认` 用户应能通过 Web 页面连续完成研究闭环，而不是在多个 API 表单之间手动拼接结果。

## 主路径

1. 用户进入 Dashboard，查看数据覆盖、系统配置、最近回测、最近报告和重构覆盖状态。
2. 用户进入数据中心，确认 A 股行情、交易日历和同步状态可用。
3. 用户进入因子分析，选择股票池和因子，查看单股快照、截面摘要和 Top N 排名。
4. 用户进入策略回测，选择策略、标的、区间和参数，提交单次或批量回测。
5. 用户进入报告中心，查看回测详情、批量对比和历史运行记录。
6. 用户进入 AI 分析，选择标的，生成结构化研究摘要，查看依据和风险提示。
7. 用户进入配置中心和重构溯源，确认数据源、模型配置、默认参数和五仓库采纳边界。

## 异常路径

- 数据缺失：页面显示缺失范围、当前数据源状态和可执行的同步入口。
- 因子无结果：页面显示股票池、日期、因子 ID 和可重新运行的入口。
- 回测失败：页面显示失败状态、错误摘要、请求参数和日志摘要。
- AI 分析不可用：页面显示当前 mock/真实 LLM 状态、不可用原因和风险提示。
- 配置缺失：配置中心显示缺失项、默认值来源和待人工确认项。

## 状态流转

- 数据同步：`idle -> running -> completed/failed`。
- 因子计算：`pending -> running -> stored -> readable`。
- 回测任务：`pending -> running -> completed/failed -> reportable`。
- AI 分析：`draft -> generated -> reviewed_pending`。
- 报告：`created -> readable -> archived_candidate`。

## 待确认事项

- `待确认` 本地数据导入与清洗流程在真实 provider 接入后的状态细分。
- `待确认` 回测结果与研究结论是否需要人工确认后才能进入正式报告。
- `待确认` AI 分析报告是否需要单独的免责声明确认交互。

## 双模式回测主流程

- `已确认` 策略准备：新建或选择策略 -> 编辑参数与源码 -> 校验 -> 保存不可变版本 -> 冻结源码 hash。
- `已确认` 独立账户批量回测模式：冻结股票池与数据版本 -> 多股票独立资金并发回测 -> 区分建仓、未建仓、失败 -> 仅对建仓结果计算绩效汇总 -> 输出完整筛选漏斗。
- `已确认` 组合资金池模式：冻结股票池与数据版本 -> 建立共享账户 -> 按交易日生成多股信号 -> 组合分配与撮合 -> 生成账户净值、持仓与归因 -> 输出组合分析。
- `已确认` 报告衔接：报告中心按回测模式读取结果，独立账户批量回测报告关注命中率与建仓样本，组合报告关注整体账户收益、风险与暴露。

## 阶段 87 独立因子研究主流程

1. 用户进入 F0 看板，查看因子定义、能力状态和最近报告。
2. 用户在 F1 选择因子、股票池、区间、复权、前瞻周期、预处理和成本假设。
3. 系统先执行预检，选择最新合格 published 版本，计算必需成员交集并冻结股票池与上下文哈希。
4. 预检 ready 后创建持久任务；用户在 F2 显式启动、观察进度、协作式停止或失败重试。
5. 任务按标的分批读取只读行情，逐日执行点时成员/行业连接、因子计算、预处理和未来收益计算。
6. 系统保存观测和不可变报告；用户在 F3 查看统计证据并对同口径不同股票池报告进行比较。
7. 指数或行业事实缺失时返回稳定 unavailable 原因，不触发外部同步或演示回退。
## 阶段 91 数据源与质量修复流程

1. 选择受控数据源与能力，执行契约或真实只读探测；记录结构化证据，不改变启用状态。
2. 预览同步任务，冻结路由、限频、并发、重试、退避与主机策略；执行器回显实际采用值。
3. 质量扫描生成问题，按规则决定是否阻断发布。
4. 创建重拉、历史补齐或纠错覆盖工单；原始事实保持不变。
5. 工单结果进入不可变数据版本，再执行定向复检；问题不再复现后关闭并解除发布门禁。
