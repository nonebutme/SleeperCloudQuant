# “拂经v2”人工验收操作指南

## 1. 验收基线

- 本地地址：`http://127.0.0.1:8010`
- 策略：`拂经v2`，ID `fujing_v2`，当前版本 `v5`
- 数据集：`A股日线行情`，ID `a_share_daily`
- 时间：2020-01-01 至 2026-07-24
- 复权：原始价 `raw`
- 初始资金：1,000,000
- 基准：`000300.XSHG`
- 股票池：`000001,600000,000333,600519,300750,601318,000858,600036`

## 2. 验收策略数据集与创建流程

1. 打开左侧菜单“策略数据集”。
2. 在左侧分类选择行情类数据，打开“A股日线行情”卡片。
3. 依次检查“关于数据集、使用文档、研究应用、策略示例”。
4. 在“使用文档”中确认代码区使用策略工作台同款代码样式，并看到查询及策略引用示例。
5. 点击导入/使用示例，进入“策略工作台”。
6. 新建策略时，把名称改为“拂经v2”、ID 改为 `fujing_v2`，粘贴 [scripts/fujing_v2_strategy.py](../../scripts/fujing_v2_strategy.py) 的代码。
7. 确认数据集声明包含 `a_share_daily`，参数包含 `execution_price=open`、`position_size=1`。
8. 点击代码校验，再点击保存。当前项目已经保存到 `v5`；v5 仅增加详细中文注释，人工验收时可直接选择“拂经v2 v5”。

验收点：数据集详情地址不应被工作台初始化覆盖；参数导入后不应丢失；保存后策略列表可见“拂经v2”。

## 3. 配置公共回测参数

1. 在“策略工作台”选中“拂经v2 v5”。历史验收任务使用 v4，二者回测逻辑和结果一致。
2. 进入回测任务创建区。
3. 设置开始日期 `2020-01-01`、结束日期 `2026-07-24`。
4. 设置复权为 `raw`，初始资金为 `1000000`，基准为 `000300.XSHG`。
5. 参数确认 `execution_price=open`、`position_size=1`。
6. 应用公共配置。

## 4. 模式一：单品种测试

1. 选择“单品种测试”。
2. 标的输入 `000858.XSHE`。
3. 创建并执行任务，等待状态变为“完成”。
4. 在任务中心打开“分析报告”。

已保存验收任务为 `single-f062258889f4`，Run 为 `single-run-20260809014304-kksh`。预期看到总收益约 -16.17%、最大回撤约 -19.08%，成交时间为 09:30，执行方式为开盘价。

## 5. 模式二：独立账户批量回测

1. 选择“独立账户批量回测”。
2. 输入 8 只股票：`000001,600000,000333,600519,300750,601318,000858,600036`。
3. 股票上限设为 8，并发数设为 4。
4. 创建并执行任务，等待进度达到 8/8。
5. 打开任务级分析报告，并切换实际建仓股票查看单股报告。

已保存验收任务为 `screening-20260809014309-5zrc`。预期为 7 只建仓、1 只无入场、0 失败；统计只包含实际建仓股票，不得生成虚假的合并账户净值。

## 6. 模式三：共享资金组合回测

1. 选择“共享资金组合回测”。
2. 输入同一 8 只股票。
3. 股票上限设为 8，最大持仓设为 3，总暴露设为 1，并发数设为 4。
4. 创建并执行任务，等待状态变为“完成”。
5. 在任务中心点击“分析报告”。首次生成约需 38 秒，重复打开应接近即时。

最终验收任务为 `portfolio-20260809015504-r6kw`，Run 为 `portfolio-20260809015504-r6kw-shared-portfolio`。验收时重点检查：

- 股票池显示 `shared:8 A-shares`，最大持仓为 3。
- 成交均标记 `execution_price_mode=open`，成交时间 09:30。
- 平安银行 `000001` 成交价应在约 10–18 元区间，不能出现 3,000 点以上的指数价格。
- 总收益约 +0.03%，最大回撤约 -20.32%，已平仓胜率 57.65%。
- 页面胜率说明为“盈利平仓 / 已完成交易”，不能再显示旧的“估算胜率 73.97%”。
- 数据质量门禁为 `ready`，7 个维度，证据等级为“高”。

## 7. 数据缺失时的处理

本次验收数据完整，没有执行补数。若人工验收出现“数据不可用、日期覆盖不足或质量未通过”：

1. 打开“数据中心”。
2. 进入 M4 的 A 股日线资产。
3. 检查股票、日期范围、复权方式、质量状态和缺口列表。
4. 对明确缺口执行补数/修复，并等待质量检查通过。
5. 记录新的数据版本，再回到策略工作台重新创建回测任务；不要复用绑定旧数据版本的结果。
