# 阶段 68A｜策略回测界面使用说明

## 1. 打开工作台

- 访问 `http://127.0.0.1:8017/?page=backtest`，或从左侧导航点击“策略回测”。
- 顶部四步状态依次表示：选择策略、选择模式、配置任务、运行与报告。
- 五个工作区分别是：任务总览、策略管理、独立账户批量回测、投资组合回测、结果分析。

## 2. 先选择或创建策略

1. 打开“策略管理”。
2. 在策略库点击一个策略，工作台顶部会显示当前策略及版本。
3. 需要自定义时，在策略编辑器点击“新建策略”，填写策略 ID 和名称，编辑 Python 策略代码。
4. 点击“校验代码”；校验通过后点击“保存新版本”。
5. 已保存策略再次从策略库选中后，才作为后续双模式任务的当前策略。

“单股快速试跑”用于小范围确认策略能否运行，不代替两种正式批量回测模式。

## 3. 模式一：独立账户批量回测

适用目标：同一策略对所选范围内每只股票分别使用独立虚拟资金并发回测，最后只汇总实际建仓的股票。

1. 打开“独立账户批量回测”。
2. 选择范围：全部 A 股、上交所、深交所、北交所，或填写指定代码。
3. 设置开始日期、结束日期和复权方式。
4. “股票上限”填 `0` 表示当前全部 A 股；首次验证建议先填 3～10。
5. 点击“创建任务”，确认配置摘要无误。
6. 点击“启动 / 恢复”开始执行。
7. 运行中可点击“暂停”；暂停或异常中断后可继续“启动 / 恢复”；必要时可取消。
8. 页面实时显示总数、已处理、已建仓、未建仓、失败、吞吐率、耗时和预计剩余时间。
9. 下方结果表只列出建仓股票，供后续统计分析和分类比较。

高级参数：

- 并发数 `0`：系统自动选择并发，当前上限 32。
- 调度批次 `0`：系统自动选择有界批次。
- 重试：单股失败后的自动重试次数。
- 单股资金：每只股票各自独立使用的虚拟初始资金。

## 4. 模式二：投资组合回测

适用目标：模拟真人使用一个资金池，在多只股票之间统一分配现金和持仓。

1. 打开“投资组合回测”。
2. 设置股票范围、日期、复权和股票上限。
3. 设置最大持仓数与资金使用率。
4. 点击“创建组合任务”，确认配置摘要中的组合约束。
5. 点击“启动 / 恢复”。
6. 任务按交易日统一推进，执行共享现金、持仓上限、A 股 T+1、100 股整手、先卖后买和交易费用约束。

高级参数：

- 准备并发数：用于股票数据和信号准备，不代表创建多个资金池。
- 初始资金：整个组合唯一共享的初始资金。

## 5. 查看任务与报告

1. 打开“任务总览”。
2. 可按模式、状态、策略 ID 或任务名称筛选。
3. 选择任务查看详情；对可执行状态可直接启动或恢复。
4. 已完成任务可打开专业报告。
5. 独立账户批量回测报告侧重建仓样本的统计分布、收益风险、行业/概念/时段分类比较；投资组合回测报告使用当前报告中心的组合模板。
6. “结果分析”用于查看单次回测指标、实验索引、参数对比和结果明细；“报告中心”用于最终专业报告与导出。

## 6. 推荐验收顺序

1. 先用 1 只股票做“单股快速试跑”，确认策略代码和参数可运行。
2. 用 3～10 只股票跑“独立账户批量回测”，检查建仓筛选和逐股结果。
3. 用相同股票跑“投资组合回测”，对比两种资金语义的差异。
4. 确认报告正确后，再将独立账户批量回测的股票上限改为 `0` 执行全 A 股。
5. 全市场任务运行期间优先观察吞吐率、失败数和预计剩余时间，需要释放资源时使用暂停。

## 7. 关键边界

- 两种模式不能混用：独立账户批量回测是每股独立资金；投资组合回测使用一个共享资金组合账户。
- “创建任务”只冻结策略版本、股票范围和数据窗口；需再点击启动。
- 全市场回测使用本地已验收 A 股数据库，不依赖运行时临时抓取行情。
- 当前系统用于研究与回测，不承诺实盘交易执行。
