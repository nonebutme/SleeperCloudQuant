# 因子分析标准业务流程 v1

## 1. 状态

- 状态：已确认，作为单因子、多因子、准入发布和生命周期改造的业务基线。
- 范围：因子定义、数据准入、研究任务、研究报告、复合因子、验收、策略登记和发布后监控。
- 边界：因子研究输出预测信号及历史证据；账户持仓、成交、资金和风险约束继续由策略回测负责。

## 2. 三类判断标准

1. **硬门禁**：数据版本、点时事实、未来信息、不可变版本、研究上下文和可复现性；不满足时必须阻断。
2. **验收政策**：覆盖、样本、Rank IC、显著性、分层收益、成本、稳健性和多因子增量贡献；数值随研究类型配置，并在样本外结果解封前冻结。
3. **观察指标**：用于解释因子，不单独决定准入。

任何受控研究必须绑定一份不可变 `AcceptancePolicy`。探索研究可以试算，但不能进入策略准入。

## 3. 因子定义与数据准入

```mermaid
flowchart TD
  A[提出研究假设] --> B{已有因子定义}
  B -->|定义不变| C[选择精确版本]
  B -->|没有| D[创建草稿]
  B -->|需要修改| E[基于旧版创建新草稿]
  D --> F[公式与依赖校验]
  E --> F
  F --> G{校验通过}
  G -->|否| H[修改或放弃]
  G -->|是| I[冻结新版本]
  C --> J[解析数据依赖]
  I --> J
  J --> K{数据版本和点时事实就绪}
  K -->|否且可补| L[进入数据中心补数与质检]
  K -->|否且不可补| M[标记不可研究]
  L --> J
  K -->|是| N{研究级别}
  N -->|探索| O[允许抽样 禁止发布]
  N -->|受控| P[完整治理股票池]
  O --> Q[预检]
  P --> Q
  Q --> R{预检结论}
  R -->|阻断| S[修复数据或配置]
  R -->|警告| T{记录后接受}
  T -->|否| S
  T -->|是| U[冻结研究上下文]
  R -->|通过| U
```

硬门禁包括：精确因子版本、已发布且质量通过的数据版本、点时股票池、交易状态、生命周期、未来收益覆盖、预处理顺序、成本假设、样本划分和稳定的 `context_hash`。

## 4. 单因子研究

```mermaid
flowchart TD
  A[创建并启动任务] --> B{执行状态}
  B -->|运行中| B
  B -->|停止或中断| C{继续}
  C -->|是| A
  C -->|否| D[保留上下文并结束]
  B -->|失败| E{可重试}
  E -->|是| A
  E -->|否| F[修复后创建新任务]
  B -->|部分完成| G[部分证据报告 禁止发布]
  B -->|完成| H[完整单因子报告]
  H --> I{覆盖和样本合格}
  I -->|否| G
  I -->|是| J{预测方向和统计证据成立}
  J -->|否| K[未通过 保留失败证据]
  J -->|与预注册方向相反| L[登记新假设 不事后翻转]
  J -->|是| M{样本外和稳健性通过}
  M -->|否| N[研究候选 禁止准入]
  M -->|是| O{成本与实施约束可接受}
  O -->|否| N
  O -->|是| P[合格单因子候选]
```

报告至少包含：覆盖与失败原因、原始及处理后分布、IC/Rank IC/ICIR、稳健显著性、Q1—Q5、Top-Bottom、IC 衰减、因子秩自相关、分组成员换手率、行业分析、样本内外、滚动窗口、成本压力和结论边界。

## 5. 多因子研究

```mermaid
flowchart TD
  A[选择合格单因子候选] --> B{研究上下文兼容}
  B -->|否| C[统一口径重算或排除]
  C --> A
  B -->|是| D[方向与预处理对齐]
  D --> E[因子值和 IC 序列相关分析]
  E --> F{高冗余}
  F -->|是| G[保留代表 因子簇合成或正交化]
  F -->|否| H[保留候选]
  G --> H
  H --> I[定义组合配方]
  I --> J[冻结训练 验证 样本外]
  J --> K[训练和验证]
  K --> L[冻结最终配方]
  L --> M[解封一次样本外]
  M --> N{样本外通过}
  N -->|否| O[组合未通过 禁止用测试集调参]
  N -->|是| P[增量贡献与消融检验]
  P --> Q{优于最佳单因子且贡献可解释}
  Q -->|否| R[拒绝 简化或新编号重研]
  Q -->|是| S{权重 换手 成本稳定}
  S -->|否| R
  S -->|是| T[合格复合因子候选]
```

首期只允许等权秩组合、固定权重组合和因子簇内等权。动态 IC 权重、回归和机器学习组合不进入首期。

## 6. 准入、发布与监控

```mermaid
flowchart TD
  A[单因子或复合因子候选] --> B{验收材料完整}
  B -->|否| C[研究候选 禁止发布]
  B -->|是| D[执行冻结验收政策]
  D --> E{审核结论}
  E -->|拒绝| F[保留失败证据]
  E -->|需修改| G[创建新版本或新研究]
  E -->|通过| H[生成准入记录]
  H --> I[登记精确 artifact_id]
  I --> J[生成策略调用声明]
  J --> K[进入策略回测]
  K --> L{策略通过}
  L -->|否| M[拒绝策略 不自动否定因子]
  L -->|暴露因子问题| N[重新打开因子复核]
  L -->|是| O[策略候选]
  I --> P[发布后监控]
  P --> Q{异常}
  Q -->|无| P
  Q -->|数据完整性或依赖失效| R[暂停新增使用]
  Q -->|统计衰减| S[人工复核]
  R --> T{可修复}
  T -->|是| U[新版本重新研究和验收]
  T -->|否| V[停用 不删除历史]
  S --> U
```

## 7. 状态模型

| 对象 | 状态 |
| --- | --- |
| 因子定义 | `draft / frozen / deprecated` |
| 研究任务 | `ready / running / completed / partial_completed / failed / stop_requested / stopped / interrupted` |
| 研究结论 | `complete / partial / unavailable / rejected / candidate` |
| 研究制品 | `research_ready / invalid` |
| 准入审核 | `pending / approved / rejected / revoked` |
| 策略登记 | `unregistered / registered / suspended / deprecated` |

研究完成只生成 `research_ready` 制品；只有 `approved + registered` 的精确制品才允许新策略使用。历史任务和历史制品保留，不自动追随最新版本。

## 8. AcceptancePolicy 合同

政策至少冻结：

- 数据质量、最低覆盖和允许缺失原因；
- 最小有效截面、截面样本和独立调仓期；
- 方向一致 Rank IC、ICIR、正值比例；
- HAC 或块 Bootstrap 及多重检验方法；
- 分层单调性、Top-Bottom 毛收益和成本压力；
- 样本外、滚动窗口、年度、市场阶段和股票池稳定性；
- 多因子相关性处理、增量贡献、消融和权重集中度；
- `approved / candidate / rejected / unavailable` 的决策规则。

数值阈值不得从样本外结果倒推；政策变更必须创建新政策版本和新研究任务。
