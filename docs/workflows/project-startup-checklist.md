# 项目启动与阶段切换清单

## 当前日常入口

- 双击根目录 `启动系统.cmd`，从 `http://127.0.0.1:8010/` 访问全部正式模块。
- 双击 `停止系统.cmd` 停止服务；内部脚本和开发候选不是另一个日常入口。
- 细则见 [统一启动说明](windows-double-click-launchers.md)。

## 已完成的启动骨架

- 项目级 `AGENTS.md`、`manifest.md`、项目画像和验证模板已存在。
- 需求、交互、架构、考古、复用、验证和追踪目录已建立。
- 五仓库考古与复用边界已形成历史文档。

## 进入阶段 77.1 前必须确认

- [ ] 用户确认“查看结果”只承担事实、指标和证据浏览。
- [ ] 用户确认“查看分析”承担解释、可信度、风险和证据缺口。
- [ ] 用户确认三种回测模式各自的默认首屏与详细层级。
- [ ] 用户确认是否保留统一查看器外壳，以及两个入口的返回路径。
- [ ] 产品、业务、交互验收标准已冻结。

## 每轮开发结束检查

- 角色是否与实际改动范围匹配。
- 是否保留最小必要角色交接与验证证据。
- 是否新增或引用记忆；没有则明确记录空列表。
- 是否更新对应阶段文档和验收报告。
- 是否区分局部验证与全系统发布判断。
- 是否写入 `traces/task_logs.jsonl`。
