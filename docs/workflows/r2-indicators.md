# R2 指标使用流程

入口始终为 `启动系统.cmd` → `http://127.0.0.1:8010/`。

1. **数据集 → 指标库**：选择指标，查看来源/公式/输出；设置参数和复权，点击“注册至数据集”。内置 SMA、EMA、WMA、RSI、MACD、ATR、BBANDS、ROC；自定义须通过受限表达式与数值样例校验。
2. **数据中心 → 数据资产 → 指标值浏览**：选配置、证券、日期查询；查看值、缺值状态、可用时间、输入批次。更新行情后下次查询自动重算，无需发布版本。
3. **直接写策略**：选配置，点击“导入策略调用示例”；编辑信号后按既有规则保存、校验、回测。复权须匹配，示例不代表有效策略。
4. **需要因子研究时**：选输出及原值/取负/价格偏离转换，点击“生成对应因子”；系统填写因子分析配置，不自动启动研究。
5. **因子研究 → 分析**：检查日期、股票池、预处理与复权，启动研究，阅读报告。算法校验不等于投资价值验证。
6. **数据集 → 刷新分析成果**：选择精确制品，填写选用依据，注册至策略数据集；可导入绑定该制品的策略示例。

配置可停用，不删除已完成研究记录。指标值只按当前规范行情计算；旧因子成果保留证据，但不能据此声称旧行情可回退或任意区间可用。
