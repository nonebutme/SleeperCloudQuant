# 阶段 70：系统颜色语义统一

## 规则

- 财务盈利、上涨、正收益：红色 #c43d3d。
- 财务亏损、下跌、负收益、回撤、成本损失：绿色 #16845b。
- 任务成功/失败、评分等级、风险警示继续使用独立状态色，不与行情涨跌色混用。

- 实验对比年化收益、最大回撤图表。
- 通用回测结果表和报告表的财务列。
