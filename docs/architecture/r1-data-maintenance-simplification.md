# R1 数据中心简明维护整改

状态：2026-09-13 用户已确认实施；当前为候选代码，尚非正式数据验收结论。

## 需求与实现

| 需求 | 候选实现 |
| --- | --- |
| 一次更新 | “更新数据”依次刷新目录、日历、基准和 raw/qfq/hfq，检查后自动生效。 |
| 免手动发版 | 常规更新自动设置当前数据；页面显示更新记录，不提供历史回退按钮。 |
| 失败不污染 | 下载结果暂存；事实、质量记录和当前指针在同一 SQLite 事务提交或撤回。 |
| 重试不重复下载 | 同一任务复用通过哈希检查的成功下载；失败响应不缓存。 |
| 无变化不造记录 | 无价格缺口且参考数据未变化时不产生新数据版本。 |
| 简化纠错 | 勾选同类 OHLCV 问题、逐项核对原值及修正值，一次确认后整批复检生效；任一失败整批撤回。 |
| 指定重拉 | 一次确认后只重拉所选行情键/缺口，自动复检生效；不刷新无关目录、日历或其他行情。旧排队 API 保留兼容。 |
| 历史修复授权 | 保留证据、授权及精确确认；新增一次复检并生效接口，不另设默认。 |
| 研究输入一致 | 三种回测与因子任务加读保护；已更新且未保留输入的旧任务明确拒绝重算。 |

## 存储与运行边界

- 保留一份规范事实库；不为每次更新复制整库。
- `<主库>.maintenance.sqlite3`：任务及下载缓存；成功后清除该任务下载正文，失败/中断缓存保留 7 天，过期需新建任务。历史摘要保留。
- `<主库>.maintenance-worker.sqlite3`：跨进程更新互斥；`<主库>.research-lock.sqlite3`：研究读保护；均非行情副本。
- SQLite WAL/事务日志仍可能增长；清除缓存正文不等于立即缩小 SQLite 文件。不自动压缩、删除旧库或备份。
- 一次维护使用同一事务连接，内部写入串行；下载期间持有主库写锁。生效等待读保护释放，30 秒超时则撤回、可重试。
- 已启用统一维护后，独立参考数据写入接口拒绝执行；页面仅保留参考数据只读预览。
- 定时调度已接入原子提交及自动生效；持久化下载重试缓存覆盖统一更新与旧单次行情任务入口，尚未覆盖定时调度内部参考下载。
- 本轮不操作正式行情、不裁决历史人工候选、不关闭历史工单、不清理已有数据库、不提供历史整库回退。
