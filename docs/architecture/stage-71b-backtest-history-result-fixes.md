# 阶段 71B｜策略回测历史任务与结果分析修正

## 范围

本阶段修复单股回测历史任务找回、双模式任务列表终态同步与选中态、交易明细分页边界、导出下载提示、独立选股收益分布、行业比较排序、默认查询日期/前复权，并将策略库页签置于单股测试之前。

## 实施要点

- SQLite 增加非删除单股回测历史列表查询，Web 工作区提供历史列表、结果入口和确认删除。
- 任务轮询进入 completed/failed/cancelled 后刷新独立选股与共享资金池列表；当前卡片增加高亮。
- 交易分页依据 `has_next` 控制按钮，导出生成浏览器下载文件并弹窗说明默认下载目录。
- 收益分布使用固定收益区间横轴、票数纵轴；历史行业比较支持默认/正序/倒序循环。
- 回测查询表单默认本年 1 月 1 日至当前月初，复权默认前复权；页签顺序为策略库、单股测试、独立选股、共享资金池、研究实验。

## 边界

不改变独立选股与共享资金池的资金语义，不执行实盘交易，不启动全市场长周期任务。
