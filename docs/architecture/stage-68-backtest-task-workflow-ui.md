# 阶段 68：回测任务流程与进度可视化

## 用户问题

- 单品种测试、独立账户批量回测和投资组合回测缺少统一进度展示。
- 任务总览、执行工作区和结果分析之间缺少清晰跳转。
- 原始 JSON 默认展开，任务状态、下一步操作和结果入口不直观。

## 界面结构

策略回测工作台调整为六个工作区：

1. 任务总览
2. 单品种测试
3. 策略库
4. 独立账户批量回测
5. 投资组合回测
6. 结果分析

顶部流程统一为：选择策略、选择模式、配置任务、执行任务、查看结果。

## 任务总览

- 三类模式状态板同时展示单品种测试、独立账户批量回测和投资组合回测的当前任务。
- 统一任务目录支持模式、状态、策略 ID 和关键字筛选。
- 每个任务直接展示状态、策略版本、回测日期、股票数量、进度条和处理量。
- 每个任务提供进入工作区、启动或恢复、查看结果三个明确操作。
- 任务选择后展示结构化执行详情，不再默认显示原始 JSON。

## 进度口径

### 单品种测试

- 请求执行期间显示“正在读取行情并执行策略”和实时耗时。
- 计算完成后切换为“正在载入指标和交易明细”。
- 结果载入后显示 100%，自动进入结果分析。
- 执行失败时保留失败阶段和错误信息。

### 独立账户批量回测

- 使用后端真实 progress 数据展示百分比、已处理/总数、吞吐、耗时和 ETA。
- 同时显示建仓、未建仓、失败、有效并发和调度批次。
- 运行中每两秒轮询，不伪造客户端进度。

### 投资组合回测

- 后端当前只提供任务状态和最终结果，因此运行中使用不确定进度条。
- 明确区分待执行、运行中、完成、失败和中断阶段。
- 完成后显示冻结股票、实际执行、收益、回撤和成交数。

## 结果与报告

- 结果分析顶部固定显示当前选中任务或最近单品种测试。
- 单品种测试完成后自动进入结果分析。
- 已完成的双模式任务可从总览直接查看结果，并打开专业报告。
- 原始任务 JSON、输入快照和完整结果 JSON 默认折叠为技术详情。
