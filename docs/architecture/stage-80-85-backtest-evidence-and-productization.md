# 阶段 80—85：回测证据与报告产品化

- 冻结日期：2026-07-28
- 适用模式：单品种测试、独立账户批量回测、投资组合回测
- 总原则：只展示可追溯证据；缺少底层序列时返回 `unavailable + reason`，不得填 0、演示值或由持仓反推原始因子。

## 阶段 80：原始策略因子证据

### 信号契约

版本化策略除 `generate_target_weights` 外可选实现 `generate_signal_scores`。隔离工作器一次执行并返回：

- 原始连续分数；
- 目标持仓权重；
- 信号日期；
- 策略版本及源码 SHA-256；
- 观测时点 `bar_close`。

`raw_result.signal_evidence` 使用紧凑行 `[date, raw_score, target_weight]`。单品种 Run 不执行横截面标准化；标准化必须在同日股票池上完成。旧任务未保存原始分数时保持不可用，策略持仓暴露 IC 不冒充原始因子 IC。

### 对照口径

原始因子 IC 与策略暴露 IC 分别使用 `t` 日证据和 `t+1` 日复权收益。`conversion_loss` 比较两者绝对 IC，定位分数到仓位、过滤和执行的损耗。

## 阶段 81：行业与市场环境稳定性

### 行业

- 历史行业分类按 `valid_from <= t <= valid_to` 解析；
- 行业内 IC 在每个行业内部计算；
- 行业中性 IC 先在每个行业内对信号和收益去均值，再计算全横截面 IC；
- 缺少历史行业覆盖时明确不可用，不使用当前分类回填。

### 市场环境

- 趋势与波动标签只使用当前观察日前 20 期市场横截面平均收益；
- 趋势分上涨、下跌、震荡；
- 波动分高波动、低波动；
- 输出每个状态的 IC、Rank IC、IC 正数比率、多空收益和样本数。

## 阶段 82：单品种证据

- 单品种新 Run 保存真实 OHLCV 引用，K 线与成交按同一日期轴展示；
- 月度收益由月末账户价值相对上月末账户价值计算；
- 超额回撤由真实超额净值计算；
- 训练、验证、样本外固定按 60%/20%/20% 时间顺序切分；
- 参数敏感性只读取绑定同一数据快照的参数网格实验；未绑定时不可用。

## 阶段 83：投资组合执行与容量

- 日 VWAP 仅在行情 `amount/volume` 或 `amount/(volume×100)` 能与收盘价量级核对时保存；
- 买入成交价高于 VWAP、卖出成交价低于 VWAP 均记为正向“执行劣化”；
- 成本矩阵是基于真实成交额的分析压力测试，明确标注 `analytical_stress_not_backtest_rerun`；
- 容量按真实成交数量/市场成交量测算，资金倍数超过 10% 日成交量时标记受限，不伪造受限场景收益。

## 阶段 84：稳健性和样本外

- 固定参数按时间顺序计算训练、验证、样本外表现；
- 走步窗口不打乱时间；
- 输出收益、年化、波动、夏普、最大回撤和窗口正收益率；
- 单参数 Run 的多重检验状态为 `not_applicable`；
- 参数网格的多重检验必须由绑定实验提供，单一 Run 不生成伪修正值。

## 阶段 85：产品化

- 报告治理对象绑定数据版本、算法版本、证据等级和免责声明；
- 页面支持 PDF 打印、表格 CSV、图形 SVG/PNG；
- 月度矩阵、行业/环境、成本/容量、样本外均支持明确空状态；
- 旧任务、部分失败任务和缺失字段保持向后兼容；
- A 股颜色继续使用红涨绿跌；
- 三模板共用同一证据构建器，避免同名指标多套口径。

## 发布边界

- 分析压力测试不等于重新回测；
- 时间切分不等于用训练期选参后的真正独立样本外实验；
- 历史任务没有原始分数时不能回填原始因子 IC；
- 本地研究报告不构成投资建议、收益承诺或实盘交易指令。
