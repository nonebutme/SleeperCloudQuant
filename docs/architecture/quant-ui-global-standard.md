# SleeperCloudQuant 全局量化 UI 规范

## 状态

- `已确认`：2026-07-30 经人工审核接受，作为项目全局 Web UI 规范。
- `适用范围`：总览、数据中心、因子分析、策略回测、AI 分析、报告中心、
  配置中心、治理页面及后续新增 Web 页面。
- `实现边界`：当前继续使用原生 HTML/CSS/JavaScript，不强制引入
  React、Vue、Arco Design、Ant Design 或 VChart。

## 设计原则

1. 数据优先：减少无业务价值装饰，提高指标、图表和表格的信息密度。
2. 风险直观：上涨/盈利使用红色和 `↑`，下跌/亏损使用绿色和 `↓`，
   颜色不得作为唯一提示。
3. 统一可控：页面只能使用全局 Token；不得建立页面私有颜色、间距和表格主题。
4. 亮暗一致：亮色研究与暗色盯盘使用同一语义 Token，不复制业务代码。
5. 本地适配：保留 PC 优先和窄屏降级，不强制整页最小宽度。

## 尺寸规范

- 间距基数：8px；允许 4 / 8 / 16 / 24 / 32 / 48px。
- 桌面侧栏：256px。
- 页面安全留白：24px。
- 按钮、输入框、下拉框：默认 32px，圆角 4px。
- 卡片：内边距 16px，圆角 6px。
- 大模块和浮层：圆角 8px。
- 指标卡：高度至少 120px，每行最多 4 张。
- 正文字号：14px；辅助文字：12px；模块标题：20px；核心指标：32px。

## 页面结构

标准页面遵循：

```text
面包屑 / 页面标题 / 全局反馈 / 主题切换
筛选与操作栏
指标卡片
图表与 VisActor VTable
分页、批量操作或技术证据
```

桌面采用 256px 左侧导航；窄屏转为顶部多列导航，并保持页面级无横向溢出。
表格内部允许独立横向滚动。

## VisActor VTable

所有适用数据表继续遵循 `docs/architecture/vtable-global-adoption.md`，并统一使用：

- 表头高度：44px。
- 行情模式：32px 行高。
- 回测模式：40px 行高。
- 因子模式：40px 行高。
- 编辑模式：48px 行高。
- 单元格字号：14px。
- 隔行背景、整行 hover、宽表冻结首列。
- 金融数值按语义着色并附加方向箭头。
- 主题切换后释放并重建 VTable，不保留旧主题 Canvas。

## 开发约束

1. 新页面必须复用 `--q-*` Token，不得硬编码新的语义颜色。
2. 新数据表必须通过 `window.AppVTable`，不得引入第二套表格组件。
3. 组件尺寸和间距优先复用本规范，不得形成页面私有尺度体系。
4. 暗色主题通过 `html[data-theme="dark"]` 切换，不复制页面业务样式。
5. 涨跌与盈亏必须同时提供颜色、方向符号和无障碍描述。
6. K线、净值曲线、表单、卡片和定义列表不视为数据表格。
7. 修改全局 UI Token、VTable 模式或页面骨架前必须更新专项验证。
