# Stage 77.1 回测结果与分析报告界面

## 1. 阶段状态

- 状态：已实现
- 用户确认来源：`量化回测分析报告界面设计方案.md`
- 实现范围：回测工作台内的“查看结果 / 查看分析”与底部原始数据区
- 业务边界：不修改回测引擎、API 路径、内部模式标识、账户模型和历史数据

## 2. 统一信息架构

三种回测模式统一采用：

1. 顶部任务上下文：任务名称、回测模式、数据周期、策略和基准。
2. 全局工具栏：统一时间窗口缩放、成本假设显示、原始数据快捷入口。
3. 查看结果：绩效摘要、核心诊断、稳定性与账户证据。
4. 查看分析：按回测模式展示专属的专业分析结构。
5. 底部原始数据：交易明细、持仓快照、账户快照。

界面展示名称固定为：

- `single` → 单品种测试
- `independent-screening` → 独立账户批量回测
- `shared-portfolio` → 投资组合回测

## 3. 三模式差异

### 3.1 单品种测试

- 六项绩效摘要。
- 净值与交易轨迹、回撤、持仓状态与浮动盈亏。
- 年度/月度稳定性、交易盈亏分布与参数敏感性入口。
- 7 维评估下沉为证据详情。

### 3.2 独立账户批量回测

- 固定显示黄色“独立账户、无限资金”警告条。
- 报告只解释横截面预测能力。
- 不生成、不拼接、不展示总汇总净值。
- 任务级统计与任务内单品种诊断分层展示。
- 持仓和账户表明确标识独立资金边界。

### 3.3 投资组合回测

- 八项绝对/超额绩效摘要。
- 组合净值、回撤和滚动超额诊断。
- 风险、市场环境、收益归因、持仓集中度和交易贡献。
- 成本敏感性、极端回撤、参数敏感性与样本内外检验入口。

## 4. 交互与颜色

- A 股颜色：红涨/盈利/正收益，绿跌/亏损/负收益/回撤。
- 买入红色，卖出绿色。
- 指标卡提供 `?` 悬浮解释。
- 核心图表支持统一时间窗口缩放。
- 图表支持 SVG / PNG 下载。
- 原始数据表支持筛选、排序和 CSV 导出。
- 桌面端多列展示，窄屏降为两列并允许 Tab 横向滚动。

## 5. 真实性边界

当前 API 未提供的证据包括部分 OHLC、月度 IC、Q1—Q5 分层时序、Brinson 归因、成本网格、行业 IC 时序和样本内外对比。

界面对此统一显示“暂无数据 / 待真实证据生成”，不使用演示值、不从独立账户拼接组合净值，也不把单品种结果解释为投资组合结果。

## 8. 显示完整性修复

用户验收发现结果抽屉显示不全。复现后确认新报告样式的 `position: relative` 覆盖了 Stage 75 结果抽屉的 `position: fixed`，导致抽屉高度从视口内可用高度膨胀为全部报告内容高度。

修复内容：

- 用 `.stage75-result-dock.report-workspace` 明确恢复固定定位。
- 纵向滚动限定在结果抽屉内部，禁止抽屉级横向滚动。
- 增加底部安全留白，避免固定原始数据 Tab 遮挡最后一段内容。
- 桌面端工具栏粘性位置下移到结果抽屉标题下方。
- 窄屏工具栏恢复普通文档流，避免占用有限视口。
- 资源版本提升到 `772`，避免浏览器继续使用旧缓存。

实测结果：

- 桌面抽屉高度由 `2768px` 恢复为视口内 `814px`，内部内容独立滚动。
- 窄屏抽屉高度由 `3292px` 恢复为视口内 `684px`。
- 桌面和窄屏页面均无文档级横向溢出。
- 滚动后结果标题、工具栏和底部原始数据 Tab 均保持可见且不互相遮挡。
