# 阶段 69：回测任务交互与进度语义修正

## 修复范围

1. 独立账户批量回测创建任务不再使用固定默认任务 ID；编号留空时由前端生成包含时间与随机后缀的唯一批次号。
2. 创建按钮在请求期间显示“正在创建...”，并明确展示成功或失败原因，避免异步异常表现为无响应。
3. 投资组合回测新增持久化 progress_json，逐股读取行情和计算策略信号时持续写入处理量。
4. 投资组合回测总体进度划分为：逐股准备 0%-90%、共享账户模拟 95%、结果落盘完成 100%。
5. 三类任务统一显示创建时间、执行耗时、策略名称、模式和短批次编号；完整任务 ID 与回测 ID 仅保留在悬停提示和技术详情。
6. A 股行情与收益方向采用涨红跌绿：上涨 #c43d3d，下跌 #16845b；任务成功/失败状态色仍保持语义色，不与行情涨跌混用。

## 数据与兼容性

- portfolio_tasks 自动迁移新增 progress_json TEXT NOT NULL DEFAULT '{}'，已有任务无需重建。
- 每次投资组合回测重新启动时重置本次 started_at，执行耗时对应当前执行批次。
- 统一任务目录 API 返回 started_at、finished_at 和投资组合回测真实 progress 字段。

## 验证结果

- 40 股真实 HTTP 探测观察到处理量依次为 0、3、7、10、14、17、21、25、28、31、35、38、40。
- 股票准备完成后显示 40/40、95%，账户模拟和结果落盘后显示 100%。
- Edge 浏览器创建独立账户批量回测任务成功，按钮恢复、输入框清空、反馈明确，生成唯一任务编号。
- 浏览器任务标题显示“双均线 + ATR动态止损 · 独立账户批量回测”。
- 投资组合回测中间进度 smoke、阶段 69 专项 smoke、JavaScript/Python 语法检查及全量正式验证全部通过。
