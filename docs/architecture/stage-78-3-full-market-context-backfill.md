## 3. 回填与恢复机制

新增持久化全市场上下文回填任务和工作项，支持：

1. 按数据集和标的拆分工作项。
2. 请求级限频、并发处理和指数退避。
3. 瞬时失败重试、永久失败隔离。
4. 进程中断后的断点恢复。
5. 完成后统一执行质量门禁。
6. 质量通过后原子发布不可变数据版本。

生命周期接口优先使用公司概况数据；公司行动使用分红送配明细接口。上游明确返回“数据为空”时记录为有效空结果，不伪造事件。
