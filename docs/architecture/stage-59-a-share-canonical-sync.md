# 阶段 59：A 股规范库迁移与全市场增量同步

## 阶段目标

- 将已确认的旧 stockmarket.db 作为永久只读迁移源。
- 在当前项目建立可去重、可增量、可断点续跑的 A 股规范数据库。
- 补齐至最近完整交易日，覆盖沪市、深市、北交所及历史证券。
- 在用户完成人工抽检前，继续冻结策略回测阶段。

## 实现结果

- 规范库：var/market/a_share_market.sqlite3。
- 唯一键：(symbol, trade_date, adjustment)。
- 复权口径：raw、qfq、hfq。
- 旧库迁移按源 rowid 分批提交并记录检查点，后出现的重复记录覆盖早期记录。
- 当前股票目录通过 AKShare 刷新；历史或非当前代码保留。
- 增量同步按每只股票、每种复权的最后日期生成目标，重复执行安全。
- 并发同步在工作线程启动前执行串行运行时预热，避免 AKShare 内部 V8 首调用竞态。
- Web/API 在规范库包含行情后优先读取规范库；规范库不可用时回退只读旧库。

## 数据源与依赖

- AKShare：1.18.64。
- pandas：3.0.3。
- 股票目录：AKShare A 股代码名称接口。
- 沪深北日线主链路：AKShare 新浪日线接口。
- 689009 九号公司 CDR：AKShare CDR raw 与腾讯复权日线组合。
- 东方财富历史接口保留为回退，但当前机器的 OpenSSL/Clash 链路存在 TLS 解密错误，不能作为主链路。
- 旧数据库始终以 SQLite mode=ro 与 query_only 访问。
