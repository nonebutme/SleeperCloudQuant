# R2 指标库实施契约

状态：用户已确认实施；候选实现已接入正式 Web，验证结果另行记录。

- 指标定义记录来源、公式、参数、输出、单位、日线复权口径、预热和缺失值规则；指标计算不做隐式 Z-score 或中性化。
- 首批内置 SMA、EMA、WMA、RSI、MACD、ATR、BBANDS、ROC；采用项目独立实现，标注种子与平滑算法，不冒充第三方软件的逐值兼容。自定义采用已有安全表达式及数值样例校验，不安装新依赖。
- 指标库包含全部定义；用户显式注册参数配置后进入 `indicator_values` 数据产品。定义/参数配置不可静默覆盖；内部自动生成标识，无需手动发版。
- 数据浏览页独立区域展示指标结果；数据集页管理已注册配置；策略通过既有数据集解析器读取，无需生成因子。
- 计算只读当前规范行情，按完整历史起点计算至请求截止日，避免递归指标种子随截取窗口变化。缺失、预热不足返回不可用；策略不得把缺值当零。
- 结果缓存绑定配置、实际输入内容与当前数据批次；查询或策略调用时自动重算失效范围，旧缓存不可充当最新结果。不后台预计算所有证券和参数组合。
- 指标转因子须显式选择输出与转换；冻结指标定义、参数、复权及转换关系，复用同一计算内核，接入既有因子分析。指标生成因子的制品须由用户明确注册后才供策略消费。
- 保持统一 8010 入口、现有回测执行约定、数据版本门禁及 VTable；不替换候选策略工作室，不重构前端。

验收：数值样例、前缀因果一致、种子一致、复权隔离、缓存失效、不可变配置、未注册拒绝、策略真实消费、因子同源及显式注册、三处页面和亮暗主题验证。

## 持久化与消费边界

- `<规范行情库>.indicators.sqlite3` 为指标旁库：定义、不可变参数配置、可重建缓存、指标—因子关系、用户制品选用记录；不复制行情主库，不提供历史行情回退。
- 缓存按配置/证券/查询范围保存；命中前重新核对真实历史输入哈希及当前数据批次。维护提交与研究读取共用现有研究锁。
- 统一日线 `trade_date`；保守声明 `available_at=当日18:00+08:00`，沿用下一交易时点执行约定。复权必须与策略/因子研究输入一致。
- 规范上市区间外、已退市或明确不可交易的行情不进入指标序列，与因子价格加载规则一致。序列内显式缺值中断窗口；不把休市、停牌补成零价格。
- 策略声明 `DATASET_REQUIREMENTS` 包含 `indicator_values`，并用 `INDICATOR_REQUIREMENTS` 固定 1–20 个配置 ID；逐证券、逐日从 `bar['datasets']['indicator_values']['items'][配置ID]['values']` 读取。
- 预热不足、日期超出当前批次、配置未注册/停用、复权不同或输入不一致均拒绝策略消费。注册配置代表算法接通，不保证每只证券每个日期都有足够历史。
- 指标衍生因子制品只有研究完成、结果可用且输入仍为当前批次时才能被用户选用；记录精确制品内容哈希与选用依据。沿用因子制品覆盖和数据版本门禁。
- 停用指标配置阻止新的直接指标消费和因子生成；已生成的因子拥有冻结定义，已有研究成果不被级联删除或改写，仍受精确制品选用和数据版本门禁约束。
- 首批只覆盖日线；非日线、多证券表达式、任意 Python 自定义指标、全部第三方指标兼容均不在本次范围。

操作见 [R2 使用流程](../workflows/r2-indicators.md)。
