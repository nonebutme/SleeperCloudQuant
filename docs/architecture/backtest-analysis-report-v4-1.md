# 策略回测统一分析报告 v4.1

## 1. 决策

`已确认`：策略回测不再刻意区分“查看结果”和“查看分析”。完成任务后只提供一个“分析报告”入口，报告内部统一使用四个顶层 Tab：

1. 回测分析
2. 交易明细
3. 持仓快照
4. 账户快照

本轮依据用户提供的《界面优化方案 v4.1》实施，不修改三种回测模式的账户语义、指标计算口径、数据库结构或数据版本绑定。

## 2. 统一报告结构

### 顶部区域

- 任务名称、模式徽章、回测周期、策略和标的范围。
- 任务实际基准及基准可用状态。
- 任务实际成本口径；成本变化仍要求重新执行回测，不在已完成结果上伪重算。
- 导出 PDF，使用浏览器打印能力生成。
- 时间窗口缩放以及 SVG、PNG 图表导出提示。

### 回测分析

- 摘要指标卡。
- 核心诊断图。
- 多维分析折叠面板。
- 数据版本与底层证据抽屉。

### 原始数据

- 交易明细支持多标的切换、筛选、排序和 CSV 导出。
- 有真实 OHLC 数据时显示 K 线和真实买卖点；接口未提供 OHLC 时明确显示不可用，不用成交价伪造 K 线。
- 持仓快照和账户快照保持账户语义隔离。

## 3. 三种模式

### 单品种测试

围绕单一标的展示收益、风险、性价比、交易特征、净值、回撤、持仓和真实成交证据。

### 独立账户批量回测

固定显示“独立账户、无限资金”警告，并明确声明本报告不提供总的汇总净值曲线。仅展示横截面统计、分层或 IC 的真实证据；缺失时显示暂无数据。

### 投资组合回测

围绕共享资金账户展示组合、基准、超额收益、回撤、持仓与交易归因、压力测试和执行可靠性。没有成本网格、参数扫描、Brinson 或行业证据时不生成演示结论。

## 4. 真实性边界

- 指标空值不会转换成 0。
- 基准未真实对齐时，不展示伪造的超额指标。
- 成本预设不可在完成结果上即时重算。
- OHLC、IC、分层收益、参数敏感性和压力测试仅在接口提供真实证据时展示。
- 红涨绿跌遵循 A 股习惯；独立账户警告使用黄色。
