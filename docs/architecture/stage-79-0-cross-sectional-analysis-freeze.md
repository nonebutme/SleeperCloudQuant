# 阶段 79.0：独立账户全市场横截面分析口径冻结

时间：`2026-07-28`

## 目标

以真实的全 A 股独立账户批量回测任务为验收对象，冻结策略暴露 IC 与
Q1—Q5 分层收益的计算口径、缺失处理和验收标准。

## 冻结口径

- 样本范围：任务中状态为 `completed` 的全部独立账户；失败账户不进入统计，
  但必须在任务完整性信息中明确披露。
- 信号：交易日 `t` 收盘后的持仓市值 ÷ 当日账户总资产。
- 收益：同一股票复权收盘价从 `t` 到下一交易日的收益率。
- IC：每日横截面 Pearson 相关系数；Rank IC 使用 Spearman 相关系数。
- 显著性：IC 序列使用 Newey-West HAC t 值；ICIR 按日频乘
  `sqrt(252)` 年化。
- 分层方向：策略暴露从高到低等数量分为 Q1—Q5，因此 Q1 为高暴露组，
  Q5 为低暴露组，长短组合为 `Q1 - Q5`。
- 最小样本：IC 至少 3 个有效股票且信号、收益均存在横截面差异；分层至少
  5 个有效股票且信号存在横截面差异。
- 零持仓：属于有效信号值 `0`，不得作为缺失值删除。
- 缺失数据：缺少账户快照、价格或下一交易日价格的股票—日期观察不进入当日
  横截面；不得填零或前向填充。
- 前视控制：信号仅使用 `t` 日收盘后已落库的账户和持仓快照，收益只使用
  `t` 之后的下一交易日价格。

## 阶段 79 验收标准

1. 真实任务的处理总数、成功数、失败数与失败原因可追溯。
2. IC、Rank IC、Newey-West t、ICIR、正 IC 比例均由真实横截面生成。
3. Q1—Q5、Q1-Q5、年化收益、最大回撤、单调性及 Spearman 检验可用。
4. 历史任务的分析结果写入既有 `summary_json`，不新增数据库结构。
5. 完成后再次读取报告不得重扫全市场数据，持久化读取目标小于 5 秒。
6. 计算结果在相同输入下确定性一致，页面不得把失败账户或不可用指标伪装为零。

## 资源约束

全市场约数百万条股票—日期观察。横截面中间数据使用双精度紧凑数组存储，
不为每个观察创建 Python 字典，也不保存重复股票代码，以控制计算峰值内存。
