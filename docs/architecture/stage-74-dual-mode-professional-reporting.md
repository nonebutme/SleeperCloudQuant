# 阶段 74：双模式专业分析报告重构

## 1. 已确认业务语义

- 独立选股是 N 个彼此独立的单股虚拟账户，任务统计只纳入实际建仓且完成的股票。
- 独立选股报告分为两层：任务级横截面统计/因子关系，以及任务内任意实际建仓股票的单股 7 维诊断。
- 共享资金池是单一资金账户、多股票持仓，报告必须使用组合净值、现金、持仓和交易证据，不得由独立单股结果拼接。
- 所有专业报告禁止用演示数值填补缺失证据；不可用能力必须明确标识。

## 2. 版本化报告契约

### 独立选股任务级报告

- 版本：`stage74-independent-dual-layer-report-v2`。
- 统计范围：`entered_symbols_only`。
- 支持固定 12 档 A 股收益分布、尾部风险、自适应技术直方图、置信区间、Bootstrap、正态性、稳健性、市场/上市板块/建仓时段/历史行业/历史概念比较。
- 因子注册表区分 `available`、`unavailable` 与 `data_asset_required`。
- Spearman 相关和分组差异只用于描述关系，不解释为因果。

### 独立选股单股报告

- 版本：`stage74-independent-single-run-seven-dimension-v1`。
- 通过任务 ID 和 Run ID 双重校验，拒绝读取不属于该任务的 Run。
- 前 6 维沿用真实回测证据评价；第 7 维改为“执行与数据可靠性”，不评价单股账户的组合分散度。
- 支持任务内股票搜索、下拉选择、上一只/下一只和真实交易明细查看。

### 共享资金池报告

- 版本：`stage74-shared-portfolio-seven-dimension-v2`。
- 模板：`shared_portfolio_strategy_evaluation_7_dimensions_v2`。
- 7 维围绕组合收益真实性、风险、风险调整收益、稳定性、交易质量与归因、成本容量、持仓分散度。
- 评分受维度完整性和证据质量门禁约束；证据不足时显示 `N/A`，不生成演示评分。

## 3. 数据能力边界

当前可直接计算：市场、上市板块、首次建仓时段、历史行业、历史概念、回测绩效特征与收益关系。

以下能力保留在因子注册表中，但必须等待相应历史时点数据资产后才能启用：

- 对齐基准收益后的 Beta/相关性；
- 历史市场情绪序列；
- 历史热点序列；
- 估值、流动性和规模因子；
- 完整样本外验证、真实容量模型和完整因子归因。

## 4. 接口与界面

- 任务级报告：`GET /api/reporting/backtest-modes/{mode}/{task_id}`。
- 独立任务单股报告：`GET /api/reporting/backtest-modes/independent-screening/{task_id}/runs/{run_id}`。
- 报告中心采用 PC 工作区布局，独立选股提供“任务统计分析 / 单股 7 维诊断”页签。
- 共享资金池主报告与附属报告解耦；附属接口失败时保留已生成的主报告并给出提示。
