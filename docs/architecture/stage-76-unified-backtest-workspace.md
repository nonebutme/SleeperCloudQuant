# 阶段 76｜统一策略回测工作台

## 1. 目标

阶段 76 将策略维护、任务创建、任务执行、结果查看和分层报告整理为一条连续工作流，同时保留单股测试、独立选股、共享资金池三种业务语义。

核心原则：

- 一个后台任务对应一个可追踪的任务实体；单股测试不再是仅查看一次的瞬时执行。
- 三种模式共用任务目录和公共查询能力，但不共用资金账户、结果聚合或分析口径。
- 创建页只负责配置和提交，任务工作台负责执行与生命周期管理，结果查看器负责证据浏览。
- 页面状态通过 URL 保存，刷新或复制链接后可恢复工作区、模式、Run 和结果页签。

## 2. 页面结构

策略回测模块分为四个一级工作区：

1. **策略工作台**：左侧策略列表，中部基本信息、版本与参数，右侧代码、校验状态和编辑器。
2. **创建回测任务**：单股测试、独立选股、共享资金池三个模式页签；公共参数只在此处显示并同步到当前模式。
3. **任务工作台**：统一列出三种任务，按模式、状态、关键词筛选；根据后端能力显示启动、暂停、取消、结果、报告、克隆、删除。
4. **其它工具**：参数扫描、参数矩阵、扫描快照及研究实验能力，避免干扰日常回测主流程。

原三种模式页面中的重复历史清单不再显示，任务生命周期统一由任务工作台管理。

## 3. 后台任务模型

阶段 76 新增持久化单股任务服务和 API：

- `POST /api/backtest/single-backtest-tasks`
- `GET /api/backtest/single-backtest-tasks`
- `GET /api/backtest/single-backtest-tasks/{task_id}`
- `POST /api/backtest/single-backtest-tasks/{task_id}/run`
- `DELETE /api/backtest/single-backtest-tasks/{task_id}`

统一任务目录 `GET /api/backtest/mode-tasks` 聚合：

- `single`
- `independent-screening`
- `shared-portfolio`

目录只统一读取模型和操作能力，不改变底层状态机。每条任务返回明确的 `capabilities` 和 `links`，前端不得推断不存在的暂停、取消或报告能力。

## 4. 结果与报告

统一结果查看器包含：

- 结果概览
- 交易明细
- 持仓快照
- 账户快照
- 分析报告

同模式任务可在查看器内切换；不同模式不放在同一个快捷切换集合中。

报告按业务模式分层：

- 单股测试：单股择时报告与真实 7 维证据。
- 独立选股：任务级全市场普查统计，加任务内任意实际建仓股票的单股诊断。
- 共享资金池：单一组合账户的净值、现金、持仓、交易及组合 7 维报告。

Run 对比只允许相同业务模式和兼容数据版本，最多 4 个；展示策略、标的范围、日期和创建时间，用户无需记忆 Run ID。

## 5. 业务边界

- 独立选股仍是 N 个独立资金账户，任务统计只覆盖实际建仓股票。
- 共享资金池仍是一个资金池、多股票持仓，不允许由独立选股结果拼接。
- 单股任务执行是不可分割的小任务，当前不伪造暂停或取消能力。
- 删除采用现有可审计语义，执行中是否允许删除由后端能力决定并在操作前确认。
- 本阶段不执行实盘交易，也不自动启动 5,528 只全市场长周期任务。
## 6. 阶段 76.1 回归修复

- 旧阶段 71/75 回测页签从 DOM 中移除，不再与阶段 76 一级工作区同时显示。
- 策略三栏重排时先保存再安置元信息、校验状态和版本历史，避免清空中栏时删除必要节点。
- 独立选股和共享资金池只隐藏旧任务列表，不再隐藏包含创建表单和操作按钮的整个模式面板。
- 页面初始化在绑定默认工作区前保存 URL 参数，确保直接链接可恢复创建工作区及对应模式。
- 静态资源版本提升为 `v=761`，避免浏览器复用阶段 76 的缺陷缓存。
## 7. 阶段 76.2 信息密度与结果动线优化

- 隐藏策略回测页内重复标题、描述以及当前策略/版本/工作区/任务/执行状态/结果状态摘要。
- 策略列表改为高密度单列，保留搜索和分类并新增名称、分类、版本数排序；列表区域固定滚动。
- 统一任务工作台改为表格式列表，支持 20/50/100 条每页和上一页/下一页，避免大量任务瀑布式堆叠。
- 结果查看器隐藏组合聚合技术明细、输入快照、旧分页导出区、实验技术块和完整结果 JSON。
- 结果查看器改为固定工作区内抽屉，不再自动滚动页面。
- “查看报告”直接在当前结果查看器切换到分层报告页签，不再跳转报告中心；报告中心保留为独立研究入口。
- 静态资源版本提升为 `v=762`。
## 8. 阶段 76.3 创建表单与视觉统一

- 策略工作台三栏使用统一高度和内部滚动，代码编辑区弹性填充；输入框、选择器和按钮统一圆角、焦点及禁用状态。
- 公共策略、日期、复权和初始资金作为三模式唯一可见入口，模式表单中的同名字段隐藏但继续参与任务提交，并随公共参数自动同步。
- 单股测试、独立选股、共享资金池统一为“模式专属字段编辑区 + 独立任务操作卡 + 固定高度任务状态区”。
- 创建前任务状态区只显示占位说明，创建或加载任务后才展示任务信息、进度和结果摘要。
- 创建页旧状态徽标及旧刷新任务按钮隐藏，任务生命周期统一由任务工作台管理。
- 任务工作台筛选条件改为工具栏卡片，四项任务统计改为等宽指标卡。
- 静态资源版本提升为 `v=763`。
