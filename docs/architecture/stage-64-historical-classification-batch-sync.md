# 阶段 64｜历史分类批量同步与离线审计增强

## 目标

为独立选股建仓汇总报告提供可恢复的历史行业/概念分类同步能力。分类数据采用生效日期区间保存，报告按回测日期解析分类，避免把当前分类倒灌到历史样本。

## 已实现

- `scripts/sync_a_share_industry_batch.py`：按当前 A 股标的批量同步 CNInfo 历史行业分类。
- `classification_sync_state`：记录任务、标的、状态、尝试次数、区间数、错误信息和更新时间。
- 失败标的可重试，进程中断后可按 `pending`/`failed` 队列恢复。
- 默认 `workers=1`。AKShare 底层 `py_mini_racer` 在多线程抓取时会触发运行时池初始化错误，当前以串行抓取保证进程稳定；并发参数仍保留用于未来更换线程安全提供方后的验证。
- 不写真实离线包，不删除分类数据；同步只更新分类历史库。

## 验证结论

- 状态机冒烟：通过，覆盖去重、完成态、失败态和失败队列恢复。
- 真实接口有限样本：1 个标的重试 3 次后成功，写入 10 个历史行业区间。
- 5 个标的测试保留了外部 CNInfo SSL EOF 失败状态，证明失败可观测且不会阻断整个任务。
- `python scripts/run_formal_verifications.py`：全部通过。
- 全市场 5528 个标的的长耗时历史同步尚未执行，需单独启动并持续观察外部接口限流/SSL 稳定性。
