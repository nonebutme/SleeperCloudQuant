# 技术边界说明

## 当前技术栈

- 主语言：Python 3.14。
- 前端：原生 HTML、CSS、JavaScript；全局遵循 Quant UI Standard，所有适用的数据表统一使用本地固定的 VisActor VTable 1.23.1。
- API：自定义 `RouteDefinition`、dataclass 请求/响应 Schema 和 Service 层。
- HTTP：Python 标准库 `ThreadingHTTPServer`，默认仅监听 `127.0.0.1`。
- 数据库：SQLite 为主；少量任务索引、配置草稿使用 JSON。
- 外部数据依赖：AKShare、pandas、PyCryptodome，仅用于已定义的数据同步与签名链路。

## 模块边界

- `domain/`：市场、回测、报告等稳定领域对象。
- `data_platform/`：行情、证券目录、交易日历、分类历史、外部 provider 与本地存储。
- `factor_lab/`：因子定义、计算、注册与结果存储。
- `backtest_kernel/`：策略执行契约、本地 SQLite 回测运行时、rqalpha 兼容网关语义。
- `reporting/`：Run 读取、批量比较、报告快照和回放。
- `config_center/`：本地配置模型、有效设置和 provider 配置。
- `app/services/`：用例编排与业务服务。
- `app/api/`、`app/schemas/`：HTTP 无关的接口契约和请求模型。
- `app/runtime/`：依赖装配、SQLite 运行存储和 HTTP 适配。
- `web/`：PC Web 展示与交互，不承载账户或统计口径裁决；`quant-ui-candidate.css/js`（保留历史文件名）承载正式全局 UI，`web/vtable-adapter.js` 是全局表格唯一接入层。

## 接口与数据边界

- 前端只依据 API 返回的 `capabilities` 决定任务操作，不推断后端不存在的暂停、取消或报告能力。
- 三种回测模式可统一任务目录、操作入口和结果外壳，但不得统一资金账户、聚合方式或分析口径。
- 策略运行绑定 `strategy_id`、不可变版本、源码 SHA-256、参数、股票池快照和数据版本。
- 结果层负责“发生了什么”的事实与证据；分析层负责解释、可信度、缺失证据和风险边界。
- 旧项目行情库保持只读；当前规范 A 股库是回测主数据源。

## 安全与权限边界

- Web 默认仅本机监听，不作为公网服务部署。
- 不在代码、文档、日志或配置草稿中硬编码真实密钥。
- 策略源码经 AST 校验并在隔离子进程中执行；不得获得任意系统访问能力。
- 所有删除采用软删除或保留审计记录的非破坏性语义。
- 不绕过行情质量、数据版本一致性或报告证据质量门禁。

## 阶段 86 数据中心边界

- 数据中心统一 API 是防腐层，复用 `AShareGovernanceStore`、`AShareSyncScheduler`、`MarketDataService` 与 `ConfigCenterService`。
- 新表只增不改；历史 `/api/market/*` 和 `/api/config/*` 保持兼容。
- 人工修正使用覆盖层，不更新或删除原始观察。
- 默认数据版本切换不改变历史 Run 的输入快照。
- 免费 Provider 失败时保留旧 `published` 版本，不自动降级为未验证数据。

## 当前已知限制

- HTTP 运行时是本地轻量服务，不具备生产级认证、限流、TLS、多租户或进程治理。
- 当前数据库为多个按职责拆分的 SQLite 文件，不支持多机并发写。
- Web 以 PC 为主；窄屏仅做降级，不承诺完整移动端产品体验。
- 正式 A 股数据版本截止 2026-07-24；较晚局部观察未发布，不参与正式研究范围。
- 数据中心能力分散在市场、配置、治理与调度模块，阶段 86 通过聚合服务收口，不重写底层存储。
- 独立因子研究仍是阶段 87 能力；阶段 86 只提供版本化数据基座和冻结接口。
- 真实外部数据授权、真实 LLM Provider 和人工审核流程仍待确认。

## 暂不引入的复杂度

- 实盘交易执行、券商网关和自动下单。
- 公网部署、多用户复杂权限和企业级审计平台。
- 为阶段 86 引入新的前端框架或重写现有服务层。
- 付费数据源、外部商业 SLA 或公网数据服务。
- 任意 Python 因子执行、完整财务因子流水线或风格风险模型。
- 未经预览、备份和二次确认的破坏性全量重建。

## M4 市场全景 P0—P3 边界（2026-07-30）

- M4 以用户点击的 K 线交易日作为 `requested_trade_date`；每个分区独立返回不晚于该日的 `effective_trade_date`，过期数据标记 `stale`，缺失数据标记 `unavailable`。
- 行业全景优先读取独立全景库；缺失时只读聚合规范库 `qfq` 日线与历史行业区间，不向 17.8GB 规范行情库增加全景表。
- 行业、概念、历史资金流、公告新闻写入独立 `market_panorama.sqlite3`，任务与工作项可审计、可停止、可重试。
- 免费源顺序：AKShare 契约；东方财富传输异常时，板块目录/历史可回退同花顺；巨潮公告可回退系统 curl。所有来源写入 `source`，不得把空结果伪装为已就绪。
- 当前项目仍为非商用本地研究；不承诺免费上游 SLA，不把未通过质量门的增量升级为正式数据版本。
