### 2.3 版本发布与回测强绑定

- 只有 `published` 版本可以被新回测解析。
- 单品种测试在执行前冻结正式版本，并写入输入快照。
- 独立账户批量回测沿用同一任务级版本绑定，不允许任务内静默混用版本。
- 投资组合回测在任务创建时冻结版本，结果与报告沿用同一绑定。
- 无可用正式版本或请求区间无数据时，返回明确的 `data_not_ready`，不写入空版本。
- 沪深 300 行情从治理表读取，可用于投资组合的正式基准收益、超额收益与年度基准对齐。

## 3. 数据源与运行边界

- 首期候选源仍为 AKShare 聚合公开数据；部分接口异常时使用同一公开上游的有界直连读取或已有本地正式事实。
- 本阶段不承诺供应商商业授权、SLA 或精确限频额度。
- 本阶段未启动全市场公司行动、历史状态或生命周期回填。
- 本阶段未修改 Windows 任务计划；应用内盘后调度属于阶段 78.2。
- 无权威来源的状态继续保留 `unknown`，禁止由行情缺失推断停牌。
