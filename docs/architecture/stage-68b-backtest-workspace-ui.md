# 阶段 68B｜策略回测界面用户友好化改造

## 阶段目标

将原先同时展开全部技术面板的策略回测页，重构为面向任务的工作台，使用户按“选策略 → 选模式 → 配参数 → 建任务 → 看进度/报告”完成操作。

## 已完成能力

- 新增四步流程状态：选择策略、选择模式、配置任务、运行与报告。
- 新增任务总览、策略管理、独立账户批量回测、投资组合回测、结果分析五个工作区视图。
- 默认仅展示任务总览，其他面板按视图切换，减少首屏信息负担。
- 独立账户批量回测与投资组合回测分别展示配置摘要，明确回测模式、策略、股票范围、日期、复权和资源/组合约束。
- 低频参数收纳到“高级参数”，保留原有字段与接口契约。
- 运行、暂停、取消按钮根据任务状态启用或禁用。
- 修复策略卡选择器误绑定任务卡的问题。
- 支持使用 `?page=backtest` 直接打开策略回测页，便于验收和定位。

## 双模式边界

- 独立账户批量回测：每只股票使用独立虚拟资金并发回测，仅建仓股票进入汇总统计。
- 投资组合回测：一个资金账户统一推进交易日，多股票共享现金、仓位上限和交易约束。
- 本阶段仅调整信息架构和操作状态，不改变两种模式的计算语义。
