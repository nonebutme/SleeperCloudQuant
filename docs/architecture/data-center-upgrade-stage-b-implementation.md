## 2. 已完成能力

### B1 数据集目录与数据源管理

- 建立 L1—L7 七层数据集目录，共登记 19 个数据集。
- 建立受控数据源注册表：`AKShare` 为已验证且启用，`BaoStock` 仅为候选且禁用。
- M1 拆分为“数据源管理 / 路由配置”，采用中文业务名称。
- 数据源探测为只读契约探测，写入计数保持为 0。
- 正式路由只允许已验证、已启用且具备对应数据集能力的数据源；同一数据集只允许一个主路由。

### B2 同步执行器 UX

- M2 按七层数据集树选择单个数据集，并根据数据集动态展示参数。
- 创建任务前必须先预览；预览令牌有效期 15 分钟，参数变化后旧令牌失效。
- 支持分片预览与选择；截断预览不会静默遗漏未展示分片。
- 增加任务详情、任务项、轮询恢复和来源路由快照。
- 停止自动创建每日同步任务，保留中断任务恢复和人工执行。

### B3 质量联动

- M3 增加来源任务、证券、规则、数据集、严重级别和状态筛选。
- 增加问题详情、处置历史、受控重拉记录和 CSV 导出。
- 处置继续强制填写原因，修正以覆盖层记录，不覆盖原始观察。

### B4 M0 与 M5 版本语义

- M0 展示研究就绪、默认版本、最新发布版本、最新观察和版本时间轴。
- M5 并列展示默认研究版本与最新发布版本，二者不再隐式合并。
- 资产查询不再在默认版本缺失时自动回退到最新发布版本。
- 现有默认版本保持 `scq-20260724-06a16f4a9fb078d9`；最新发布版本为 `scq-20260728-033fc57a7de87fe4`。
