# 阶段 75：量化工作台交互内聚

## 目标

在不改变三类回测的业务语义和后端任务状态机的前提下，降低策略选择、任务创建、结果阅读与 Run 对比的操作负担。

## 页面信息架构

- 策略回测
  - 策略库：三栏工作台（策略列表 / 编辑配置 / 校验版本）
  - 单股测试：配置、运行、历史与克隆
  - 独立选股：配置、运行、任务历史与克隆
  - 共享资金池：配置、运行、任务历史与克隆
  - 研究实验：保留既有能力，本阶段不扩展
  - 当前任务结果：作为回测页底部内嵌结果区，不再作为重复页签
- 报告中心
  - 双模式专业报告阅读
  - Run 对比工作台
- AI 分析
  - 常规 AI 分析
  - 回测联动复盘
- 报告管理
  - 研究报告包
  - 报告包归档目录
  - 报告快照

## 关键交互

1. 公共参数条统一维护策略、日期、复权和初始资金，按当前模式同步；各模式草稿独立保存在浏览器本地。
2. “创建并运行”仅编排既有创建接口和启动接口，不引入新的任务状态；创建任务仍可单独执行。
3. 历史任务支持克隆。克隆只回填配置并清除或替换原任务编号，不自动启动，尤其不会自动启动全市场任务。
4. 单股、独立选股与共享资金池结果在当前模式下展开；完整报告保留明确入口并支持 URL 状态回放。
5. Run 选择器显示策略、标的和创建时间，最多对比 4 个 Run；叠加净值/回撤曲线并并列展示核心指标。
6. 对比前展示模式与数据版本兼容提示。不同模式可以观察，但不解释为同口径结论。

## 业务边界

- 独立选股仍是多条独立资金单股回测，只统计实际建仓股票。
- 共享资金池仍是单一资金池、多股持仓的组合回测。
- 不把独立选股结果拼接为共享资金池结果。
- 不触发实盘交易。
- 不自动启动 5,528 只全市场长周期任务。
