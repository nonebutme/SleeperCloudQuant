# 独立账户策略暴露横截面分析

- 完成日期：2026-07-28
- 适用模板：独立账户批量回测
- 版本：`strategy-exposure-cross-section-v1`

## 1. 目标与语义

独立账户任务没有绑定通用的“选股因子 ID”。因此报告不得默认把任意策略解释成均线、估值或其他特定因子。

本阶段使用策略自身产生的真实账户状态定义横截面信号：

- 信号：交易日 `t` 收盘后的持仓市值 ÷ 账户总资产。
- 结果：同一标的从 `t` 收盘到下一交易日收盘的复权收益率。
- 横截面范围：任务中所有已完成的独立账户，包括从未建仓或当日空仓的账户。
- 名称：策略暴露 IC，不表述为原始因子 IC。

信号在 `t` 收盘后已知，结果使用 `t→t+1`，避免把下一日收益泄漏进当日信号。

## 2. 已实现指标

| 指标 | 计算口径 |
| --- | --- |
| IC 均值 | 每个有效交易日的持仓权重与次日标的收益 Pearson 相关系数的均值 |
| Newey-West IC t 值 | 日度 IC 均值的 HAC 自相关稳健 t 统计量 |
| ICIR | 日度 IC 均值 ÷ 样本标准差 × `√252` |
| Rank IC 均值 | 每日持仓权重与次日收益的 Spearman 秩相关均值 |
| IC 正数比率 | IC 大于 0 的有效交易日占比 |
| IC 标准差 | 日度 IC 的样本标准差 |
| 总信号股票数 | 样本期内曾出现正持仓权重的股票数 |
| 平均每期信号数 | 所有有效交易期的正持仓账户数均值，包含零信号交易期 |

IC 的单期证据门槛：

- 同一交易日至少 3 个有效标的。
- 信号值必须存在横截面差异。
- 次日收益必须存在横截面差异。

## 3. Q1—Q5 与多空收益

每期至少 5 个有效标的时：

1. 按策略暴露从高到低排序。
2. 等数量划分为 Q1—Q5；Q1 为最高暴露组。
3. 计算各组等权次日收益和累计净值。
4. 多空收益为 Q1 收益减 Q5 收益。
5. 分层单调性使用五组年化收益的 Spearman 相关。
6. 单调性 p 值使用五组排列的精确双侧检验。

不足 5 个标的时，Q1、Q5、多空年化收益和单调性 p 值均显示“不可用”，并明确显示样本门槛，不进行重复分组或插值。

## 4. 数据来源

- 持仓权重：回测运行库中的逐日持仓与账户快照。
- 次日收益：规范化 A 股行情库中与任务复权方式一致的日线。
- 日期范围：任务冻结的开始日和结束日。
- 数据范围：所有完成的独立账户，不只统计实际建仓股票。

新任务完成时，分析结果写入既有 `screening_tasks.summary_json`。不新增数据库表或字段。历史任务在首次打开报告时按需计算，并使用进程内版本缓存。

该短样本没有显示显著正向策略暴露预测能力。此结论只描述当前任务，不应外推为策略长期结论。

## 6. 已知边界

- 收盘持仓权重是策略最终暴露，不等于策略内部未经持仓约束的原始打分。
- 仅有二元或高度集中的仓位时，IC 容易出现较大绝对值，必须结合样本数、t 值和 ICIR 阅读。
- 全市场任务的证据在任务完成阶段计算；这会增加任务收尾时间，但避免每次打开报告重复扫描。
- 行业 IC、风格中性 IC 和原始因子 IC 仍需策略显式输出因子分数后才能实现。
