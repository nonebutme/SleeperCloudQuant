# 阶段 86.5：策略工作台升级

## 目标

在不重建策略、版本与回测存储的前提下，将现有策略工作台扩展为“策略发现 + 绩效详情 + 代码编辑”的统一入口。

## 页面结构

1. 策略目录支持“排行榜 / 策略列表”切换。
2. 排行榜展示前十策略归一化净值曲线，以及 3 个月收益、1 年 Sharpe 与历史长度惩罚后的 Score。
3. 策略详情顶部展示核心指标与策略说明。
4. 详情包含 `Out Of Sample Return`、`Code`、`Version Notes` 三个页签。
5. `Code` 直接复用原策略工作台三栏结构、策略详情、版本编辑和源码编辑器。

## 数据链路

- 策略与版本：复用 `/api/backtest/strategies` 及版本接口。
- 回测：复用 `/api/backtest/runs` 和结果 panel 接口。
- 排名：浏览器只读聚合最近完成回测；3M 收益以曲线末点向前推三个月计算。
- 图表：净值、回撤、基准/超额、敞口、成交额、换手、月收益、年收益；按需求排除 Capacity。

## 边界

排行榜是本地已完成回测的候选样本外视图，不等同于实盘排名，不构成投资建议。若后续数据规模显著增长，应将聚合下沉为分页服务，并明确样本内外区间字段。
