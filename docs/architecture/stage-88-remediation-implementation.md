## 88.1 指数成分权威库

- `index_component_intervals` 位于数据中心规范库，是指数成分唯一写入权威。
- 因子研究库只读委托数据中心解析，不再提供指数成分写接口。
- 新快照会闭合旧快照的开放区间，防止已退出成分在后续日期继续生效。
- 数据中心提供覆盖查询和受控同步 API：
  - `GET /api/data-center/index-components/coverage`
  - `POST /api/data-center/index-components/sync`
- 写入接口强制要求 `authorization_confirmed=true` 与非空 `authorization_reference`；授权证据随快照审计信息落库。
- 允许的指数限定为沪深 300、中证 500、中证 1000。
- 语义边界为“观测到的当前快照”，不声称具有快照日期之前的点时历史。

## 88.2 因子制品与策略消费

- 完成的因子任务自动发布不可变制品：
  - `factor_artifacts` 保存定义版本、研究上下文、数据版本、质量报告、股票池哈希和内容哈希。
  - `factor_artifact_values` 保存证券、交易日和处理后因子值。
- 制品 ID 由身份上下文和全部值的内容哈希生成；重复发布幂等，内容漂移拒绝覆盖。
- 因子制品查询：
  - `GET /api/factor-research/artifacts`
  - `GET /api/factor-research/artifacts/{artifact_id}`
- 策略声明：

```python
DATASET_REQUIREMENTS = ["a_share_daily", "factor_values"]
FACTOR_REQUIREMENTS = ["momentum_20d"]
```

- 创建回测任务时冻结 `parameters.factor_artifacts`；运行时通过 `bar["datasets"]["factor_values"][factor_id]` 读取同证券、同交易日因子值。
- 单品种、独立账户批量和投资组合三类任务均在创建时冻结数据版本；声明因子依赖时同时冻结因子制品。

## 88.3 可信度披露

- 因子报告固定披露数据版本、质量报告、因子制品、执行成本假设、市场冲击未建模及未做模拟盘/实盘验证。
- 三类回测报告统一输出 `credibility` 或 `report_governance`，明确历史模拟边界、证据缺口和免责声明。
- 因子报告页和双模式回测报告页顶部增加常驻风险提示，不以技术 JSON 代替用户可见告知。
