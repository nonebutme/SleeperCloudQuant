# 阶段 86 数据中心实现说明

## 1. 实现裁决

阶段 86 沿用阶段 78 的规范行情库、治理库与持久调度器，在其上增加数据中心控制层：

```text
Web M0—M5
  -> /api/data-center/*
  -> DataCenterService
     -> DataCenterStore（路由、异常处置、修正覆盖、默认指针）
     -> AShareSyncScheduler（预览、任务、重试、发布）
     -> AShareGovernanceStore（质量报告、不可变版本）
     -> AShareMarketStore（规范行情）
```

- 历史 `/api/market/*` 与 `/api/config/a-share-*` 继续保留。
- `DataCenterService` 是聚合门面，不复制行情、质量或版本核心逻辑。
- `DataCenterStore` 与现有组件使用同一 SQLite 文件，但只拥有新增控制表。
- 不引入依赖，不改变已有公共接口返回结构。

## 2. M0—M5 落点

| 视图 | 后端能力 | 前端能力 |
| --- | --- | --- |
| M0 总览 | 正式版本、观察日期、存储、异常、调度摘要 | 指挥舱指标、近期任务、正式/观察分离 |
| M1 路由 | 候选路由、PUT 配置、零写入探测 | 路由卡片、限频/并发、契约/实时探测 |
| M2 同步 | 无写入预览、创建、停止、失败项重试 | 预览确认、任务状态与操作 |
| M3 质量 | 异常筛选、处置审计、修正覆盖层 | 筛选、接受、隔离、人工修正 |
| M4 资产 | 按默认或历史版本读取成员 | 保留已有行情、K 线、资产和回测输入浏览 |
| M5 快照 | 版本目录、质量证据、默认指针 | 版本卡片、默认切换确认 |

## 3. 状态与安全边界

- 同步预览不落任务、不调用 Provider。
- M2 开放快捷追更与受控历史缺口修复；所有可同步数据集必须先生成零写入预览，历史模式必须填写开始日期与目标日期。全量重建仍不开放。
- 停止任务时，待执行项标记为 `stopped`；在途事务自然结束。
- 人工修正写入 `data_correction_overlays`，原始观察保持不变。
- 默认版本指针位于 `data_center_settings`；历史版本状态和历史 Run 绑定不变。
- 首次迁移自动把迁移前最新 `published` 版本设为默认，保持旧读取语义。

## 4. 免费数据源

- 继续使用现有 AKShare 依赖与 Provider 适配器。
- 路由目录保存 AKShare 接口名和主要上游，不宣称商业授权或 SLA。
- 财务报表路由存在但默认禁用，等待阶段 87 点时数据模型与质量规则。
- 实时探测只能显式触发，并且不写规范库。

## 5. 因子分析衔接

阶段 86 冻结并提供以下基础：

- 明确的默认 `published data_version_id`
- 数据版本成员和质量报告
- 未发布观察隔离
- 来源路由与同步审计
- 修正覆盖层

独立因子研究任务、IC/Rank IC、分组收益、衰减、换手率和行业分布在阶段 87 实现；不得把现有策略暴露分析结果改名为因子研究结果。
