# 阶段 71A｜策略回测 PC 工作台信息架构与任务治理重构

## 目标与范围

阶段 71A 是阶段 71 业务验收前的临时工程任务，解决策略回测页的信息重复、桌面端密度、任务归属和删除治理问题。它不改变回测算法、资金语义、行情数据或报告计算，也不执行实盘交易。

## 信息架构

策略回测顶部保留五个可见工作区：

1. 单品种测试：配置并执行一次单股策略验证。
2. 独立账户批量回测：每只股票使用独立资金，任务、进度、建仓结果和操作在本页管理。
3. 投资组合回测：一个资金池管理多股持仓，任务、组合进度和操作在本页管理。
4. 策略库：策略 CRUD、版本、源码校验和参数编辑。
5. 研究实验：参数敏感性测试、参数组合任务、固化参数对比、可复用研究方案和研究实验目录。

原“①到⑤”流程条和可见“任务总览”已移除。结果详情不占用顶部页签，由三类任务各自的“查看结果”入口进入，并提供“返回任务”。

## 任务治理与删除语义

| 对象 | 管理入口 | 删除方式 | 运行中约束 |
| --- | --- | --- | --- |
| 单品种测试 | 结果详情 | 软删除回测 run | pending/running 不允许删除 |
| 独立账户批量回测 | 独立账户批量回测任务列表、结果详情 | 软删除任务 | 必须先取消 |
| 投资组合回测 | 投资组合回测任务列表、结果详情 | 软删除任务 | 必须先取消 |
| 参数组合任务 | 研究实验 | JSON 记录软删除 | 当前为同步研究任务 |
| 可复用研究方案 | 研究实验 | JSON 记录软删除 | 当前为同步研究任务 |
| 研究实验目录 | 研究实验 | JSON 记录软删除 | 不删除关联 run 和报告证据 |

所有 Web 删除操作先弹出确认提示。软删除对象从常规列表和结果查询中隐藏，但保留删除时间、删除原因、历史结果和审计证据；任务编号与回测编号不复用。

## 研究能力解释

- 快速参数敏感性测试：围绕当前策略的数值参数生成少量组合，在同一单股和日期窗口下快速观察结果变化。
- 参数组合批量测试：创建可持久化、可重复执行的组合任务，批量运行参数笛卡尔积并按收益风险指标排序。
- 固化参数对比：保存本次参数、指标、排名和最佳组合的不可变对比快照，不重新运行回测。
- 可复用研究方案：保存策略版本、股票范围、日期窗口和参数，之后可重复执行并生成一组回测 run。
- 研究实验目录：按 run 前缀和标签组织一组相关结果，支持比较与报告复盘。
- 生成实验复盘报告：基于既有实验结果组织指标、对比和报告包，不会重新执行策略。

## 业务边界

- 独立账户批量回测仍只统计实际建仓股票，不与投资组合回测结果拼接。
- 投资组合回测仍按组合净值、现金、持仓和成交分析。
- 删除是展示层软删除，不物理清除审计和报告证据。
- 本阶段未启动 5,528 只全市场长周期任务。
