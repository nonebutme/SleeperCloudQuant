# Pattern：全市场报告采用离线预计算与版本缓存

- 时间：2026-07-28
- 分类：Pattern
- 适用范围：SleeperCloudQuant 大规模独立账户批量回测
- 验证状态：已由 5533 标的真实任务验证
- 确认次数：1

## 压缩结论

数千账户、数百万股票—日期观察的 IC 与分层收益不应在普通报告请求中临时
逐账户计算。任务完成或显式历史回填时，使用只读批量流、紧凑数值数组完成
一次计算，并把结果写入任务既有汇总；页面按任务版本读取和缓存。

## 证据

- 逐账户无索引读取在数分钟后仍未完成。
- 单次扫描与紧凑数组把真实全市场回填降至约 144 秒。
- 持久化分析读取约 0.015 秒，任务版本缓存报告读取约 0.0025 秒。

## 边界

- 缓存必须以任务 `updated_at` 等版本字段失效，不能永久返回旧任务状态。
- 失败账户必须披露并排除统计，不能填零。
- 首次历史回填仍属于离线操作，不能伪装成即时页面计算。
