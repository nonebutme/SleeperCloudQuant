# Pattern：策略原始分数与执行暴露必须分层保存

- id: `mem-staging-sleepercloudquant-pattern-point-in-time-strategy-evidence-001`
- 时间：2026-07-28
- 分类：Pattern
- 适用范围：SleeperCloudQuant 及类似量化回测报告
- 验证状态：已通过专项测试，待更多真实新任务验证
- 确认次数：1
- 来源：阶段 80—85 回测报告证据升级

## 压缩结论

策略执行证据应同时保存当时可得的原始连续分数、目标权重、时间、策略版本和源码摘要。原始因子 IC 与执行后暴露 IC 必须独立计算，不能由持仓反推原始因子，也不能把两者用同一名称展示。

## 可复用规则

- 原始分数使用可选、向后兼容的策略契约；
- 信号时间必须早于评价收益区间；
- 单品种 Run 不做伪横截面标准化；
- 旧任务缺少原始分数时返回不可用原因；
- 成本/容量近似必须标注分析压力测试，不冒充重新回测；
- 市场环境标签只使用观察时点之前的数据。
